## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, OTP input border radius |
| sm | 8px | Compact element spacing, FAQ item internal padding |
| md | 16px | Default element spacing, card padding, form field gaps |
| lg | 24px | Section padding, careers card padding, chat bubble padding |
| xl | 32px | Layout gaps, legal page section margins |
| 2xl | 48px | Page-level vertical padding, chat panel header+input area |
| 3xl | 64px | Page-level horizontal padding on desktop |

Exceptions: 44px minimum touch target for all form fields (Name, Email, Phone, Subject). 48px OTP digit box (square). 48px chat header height. 48px CTA button height. 56px AI chat FAB (circle). 56px mobile chat input height. 80px sticky sidebar top offset (header 64px + 16px gap). 256px docs sidebar width. 380px chat panel width. 520px chat panel max-height. 440px login modal max-width. 800px legal/careers max-width content.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | var(--color-base) #FFFFFF | Page backgrounds, modal background, chat panel background |
| Secondary (30%) | var(--color-surface) #F8FAFC / var(--color-card) | Contact cards, FAQ items, docs sidebar, careers cards, chat bubbles (AI), OTP input boxes |
| Accent (10%) | var(--color-primary) #2563EB | CTA buttons, active doc link border, focus rings, chat send button, inline action buttons |
| Destructive | var(--color-error) #DC2626 | OTP wrong code error text, form validation errors |

Accent reserved for:
- "Send Message" button (contact form -- solid blue bg, white text)
- "Create Account" button (login modal -- solid blue bg, white text)
- "Continue with WhatsApp" button uses green (#25D366 WhatsApp brand) -- NOT blue
- AI chat FAB (56px circle -- solid blue bg, white MessageSquare icon)
- AI chat send button (36px circle -- solid blue bg, white Send icon)
- AI chat user bubbles (blue bg, white text)
- Inline action buttons in AI chat ("Add to Quote", "Sign in")
- Active doc sidebar link (2px inline-start border blue, text blue)
- Focus rings on all React Aria components
- "Send us your CV" link on careers page

WhatsApp brand green (#25D366): used exclusively for WhatsApp CTA buttons and WhatsApp contact card icon. This is a third-party brand color exception, not a design palette addition.

Semantic status tokens (three-color rule exceptions, system-level):
- Success green (var(--color-success) #16A34A): OTP verified checkmark, contact form success confirmation
- Warning yellow (var(--color-warning) #CA8A04): not used in this phase
- Error red (var(--color-error) #DC2626): form validation inline errors, OTP wrong code, rate limit exceeded
- Info blue (var(--color-info) #2563EB): legal page translation notice banner background (var(--color-info-bg))
