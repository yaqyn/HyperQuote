# Phase 6 — UI Design Contract

> Visual and interaction contract for Website Remaining Pages: Support, Docs, Legal, Careers, Login Modal, AI Chat Widget. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn excluded per CLAUDE.md) |
| Preset | not applicable |
| Component library | React Aria Components ^1.16.0 |
| Icon library | Lucide React |
| Font | Inter (Latin), IBM Plex Sans Arabic (Arabic), Geist Mono (all numbers) |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, OTP digit box border |
| sm | 8px | Compact element spacing, FAQ item inner padding |
| md | 16px | Card padding, form field gaps, accordion content padding |
| lg | 24px | Section padding, careers card inner padding, chat bubble padding |
| xl | 32px | Page section vertical gaps, legal prose paragraph spacing |
| 2xl | 48px | Page-level vertical padding (support/docs/legal pages) |
| 3xl | 64px | Major section breaks |

Exceptions: 44px minimum touch target for all form fields (Name, Email, Phone, Subject). 48px OTP digit boxes (square). 48px chat header height. 48px submit button height. 56px chat FAB (floating action button). 56px mobile chat input height. 80px sticky sidebar top offset (header 64px + 16px gap). 256px docs sidebar width. 380px chat widget width. 440px login modal max-width. 520px chat widget max-height. 800px legal/careers page max-width.

## Typography

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body | 16px | 400 | 1.5 | Inter / IBM Plex Sans Arabic |
| Sub-heading (legal h2, section titles) | 16px | 700 | 1.2 | Inter / IBM Plex Sans Arabic |
| Legal h3 | 16px | 700 | 1.2 | Inter / IBM Plex Sans Arabic |
| Label / Muted / Sidebar link | 14px | 400 | 1.5 | Inter / IBM Plex Sans Arabic |
| Small / Meta / Character count / Legal date | 12px | 400 | 1.5 | Inter / IBM Plex Sans Arabic (text), Geist Mono (numbers) |
| Sidebar section heading | 12px | 700 | 1.5 | Inter / IBM Plex Sans Arabic |
| Legal agreement text | 12px | 400 | 1.5 | Inter / IBM Plex Sans Arabic |
| Heading (page titles, modal headings) | 30px | 700 | 1.2 | Inter / IBM Plex Sans Arabic |
| OTP digits | 16px | 400 | 1 | Geist Mono |
| Countdown timer | 14px | 400 | 1.5 | Geist Mono |
| Phone input | 16px | 400 | 1.5 | Geist Mono |
| Character count | 12px | 400 | 1.5 | Geist Mono |

Sizes used: 12px, 14px, 16px, 30px (4 sizes).
Weights used: 400 (regular), 700 (bold) (2 weights).

Consolidation notes:
- 11px (legal agreement) promoted to 12px for legibility and scale compliance.
- 20px (sub-headings, OTP digits) collapsed: sub-headings promoted to 16px bold, OTP digits demoted to 16px.
- 24px (modal headings) promoted to 30px to unify with page headings.
- 600 weight eliminated: all semibold usages promoted to 700 (sub-headings, section headings, legal h3).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | var(--color-base) #FFFFFF | Page backgrounds, modal background, chat panel background |
| Secondary (30%) | var(--color-surface) #F8FAFC / var(--color-card) | Contact cards, FAQ items, careers cards, docs sidebar, chat bubbles (AI) |
| Accent (10%) | var(--color-primary) #2563EB | "Send Message" button, "Create Account" button, "Continue with WhatsApp" button (green override), chat send button, active docs sidebar link, focus rings, chat FAB |
| Destructive | var(--color-error) #DC2626 | OTP wrong code error text, form validation errors |

Accent reserved for:
- "Send Message" submit button (blue bg, white text)
- "Create Account" button (blue bg, white text)
- Chat FAB (blue bg, white MessageSquare icon)
- Chat send button (36px blue circle, white Send icon)
- Active docs sidebar link (blue text, font-weight 700, 2px inline-start blue border)
- Focus rings on all React Aria components
- Legal page info banner (blue bg for translation notice)
- Links in legal agreement text

Special color overrides:
- "Continue with WhatsApp" button: green bg (#25D366), white text, MessageCircle icon
- WhatsApp contact card icon: green (#25D366)
- User chat bubbles: blue bg (#2563EB), white text
- AI chat bubbles: var(--color-surface) bg, var(--color-text) text
- Unread pulse badge on chat FAB: green dot (#16A34A), 10px

> **Three-color rule exception:** WhatsApp green is a third-party brand requirement. Semantic status (error red for validation) is system-level. Neither violates the brand palette.

## RTL Considerations

| Element | RTL Behavior |
|---------|-------------|
| Chat FAB | Positioned bottom-left instead of bottom-right. |
| Chat panel | Anchored to inline-end (left in RTL). |
| Chat send icon | Lucide Send flipped 180deg. |
| AI bubble corners | rounded-tr-sm instead of rounded-tl-sm. |
| User bubble corners | rounded-tl-sm instead of rounded-tr-sm. |
| Docs sidebar | Appears at inline-start (right side in RTL). Active border at inline-start. |
| TOC sidebar | Appears at inline-end (left side in RTL). |
| Legal prose | Text direction RTL. Logical margins/padding. |
| Login modal "+20" prefix | Appears at inline-start of phone field. |
