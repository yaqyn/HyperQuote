    **types/notification.ts:**
    - `NotificationType`: 'quote_ready' | 'order_update' | 'delivery' | 'payment' | 'support'
    - `Notification` interface: id, type, title, body, read (boolean), createdAt (ISO string), targetType ('quote' | 'order' | 'delivery' | 'ticket'), targetId (string)

    **lib/server/notifications.ts:** Following quotes.ts pattern with isSupabaseConfigured + dev mocks:
    - `getNotifications`: GET, input { page: z.number().default(1), limit: z.number().default(20) }, returns { notifications: Notification[], unread: number, hasMore: boolean }. Mock: 8 notifications with various types and read states.
    - `markNotificationRead`: POST (not PATCH -- TanStack Start server functions only support GET and POST; BACKEND.md specifies PATCH for REST but TanStack Start createServerFn does not support PATCH method), input { notificationId: z.string() }, returns { success: boolean }.
    - `markAllNotificationsRead`: POST (not PATCH -- same TanStack Start limitation as above; BACKEND.md specifies PATCH for REST but server functions use POST), input {}, returns { success: boolean }.

    **stores/notifications.ts:** Zustand store for UI state only:
    - `unreadCount: number` (synced from query, not from Realtime directly)
    - `setUnreadCount(count: number)`: setter
    - Use `skipHydration: true` per SSR convention

    **components/notifications/useRealtimeNotifications.ts:** Per RESEARCH.md Pattern 2:
    - Accept userId param
    - Subscribe to `postgres_changes` on `notifications` table filtered by `user_id=eq.${userId}` (RLS filter ensures user only receives their own notifications)
    - On INSERT event: `queryClient.invalidateQueries({ queryKey: ['notifications'] })` AND `queryClient.invalidateQueries({ queryKey: ['notification-count'] })`
    - MUST unsubscribe via `supabase.removeChannel(channel)` in useEffect cleanup
    - In dev mode (no Supabase configured): skip subscription, return early

    **components/notifications/NotificationItem.tsx:** Per UI-SPEC:
    - React Aria ListBoxItem
    - Layout: flex items-start gap-3 px-4 py-3 min-h-16 border-b border-[var(--color-border)]
    - Unread: 8px blue dot (w-2 h-2 rounded-full bg-[var(--color-primary)]) at inline-start + var(--color-surface) bg
    - Read: transparent bg
    - Icon by type: FileCheck (quote_ready, blue), Truck (order_update, blue), MapPin (delivery, green), CreditCard (payment, blue), MessageCircle (support, blue). Size 20px.
    - Title: Inter 500 14px var(--color-text), truncate
    - Body: 13px var(--color-text-muted), line-clamp-2
    - Time: Geist Mono 11px var(--color-text-subtle). Use Intl.RelativeTimeFormat for "2 min ago", "1 hour ago". Absolute date after 7 days.
    - onPress: marks read + navigates to target (quote/{id}, order/{id}, etc.)
    - Cursor pointer, hover bg-[var(--color-surface)] transition
  </action>
