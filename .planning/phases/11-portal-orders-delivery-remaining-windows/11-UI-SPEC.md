## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, unread dot diameter (8px) |
| sm | 8px | Compact element spacing, chip padding, toggle gaps |
| md | 16px | Default card padding, notification item padding, section content spacing |
| lg | 24px | Section padding, settings section gaps, modal internal padding |
| xl | 32px | Layout gaps between major sections, window header area |
| 2xl | 48px | Empty state icon size, action button heights, touch targets |
| 3xl | 64px | Notification item min-height, profile photo diameter |

Exceptions: 44px tab bar height (React Aria Tabs touch target -- per WAI-ARIA Tabs Pattern, interactive tab elements require minimum 44x44px touch target per WCAG 2.5.5 Target Size), 12px vertical gap between order cards (mb-12px per FRONTEND.md spec).

- "Add New Address" button
- "Invite Member" button

| Green | var(--color-success) #16A34A | Delivered badge, Confirmed badge, Verified trade license, delivery notification icon, POD confirmed state |

- Orders: Tab bar + order cards list. Eye travels: tabs > card reference + status > amount > chevron.

- Documents: Tab bar > table > download action.
- Settings: Left sidebar > right content pane.

## Interaction Contracts

### Orders Tab Navigation

- React Aria Tabs with 4 tabs: Active, Quotes, History, Drafts
- Tab count badges in Geist Mono 12px (e.g., "Active (3)")
- Active tab: Inter 400 14px var(--color-text) + 2px bottom border var(--color-primary)
- Inactive tab: Inter 400 14px var(--color-text-muted)
- Tab content crossfade: tween 150ms ease-out on switch
- Each tab loads independently via TanStack Query
- Default tab: Active

### Order Card Interaction

- Entire card is pressable (React Aria Button or Link)
- Hover: border-color transitions to var(--color-primary) at 30% opacity + translateY(-1px), 150ms ease
- Press: navigates to order detail / quote detail / tracking view
- RTL: ChevronRight flips to ChevronLeft via `icon-end` class

### Filter Chips (Quotes Tab)

- React Aria ToggleButton group
- Chips: height 32px, rounded-full, px-12px
- Active chip: var(--color-primary) bg, white text, Inter 400 14px
- Inactive chip: var(--color-surface) bg, var(--color-text-muted) text, Inter 400 14px

### Status Badge Text

- Status badges: semantic color bg + text, rounded-sm, px-6px py-2px, Inter 400 12px

### Reorder Flow

1. User taps "Reorder" button on a history card (blue outline, 32px height)
2. ReorderConfirmModal opens (GlassElevated, isKeyboardDismissDisabled)
3. Modal: "Reorder {N} items from order {REF}?"
4. Two buttons: "Edit First" (outline) + "Quick Submit" (blue bg)
5. "Quick Submit": pre-fills Material List Builder Step 2 with last-used address pre-selected, skipping Step 1
6. "Edit First": opens Material List Builder Step 1 with items pre-filled
7. Toast: "Quote request created from order {REF}"

### Delete Draft Flow

1. Hover on draft card: Trash2 icon turns var(--color-error)
2. Press delete: DeleteDraftModal opens (GlassElevated, isKeyboardDismissDisabled)
3. "Keep Draft" (outline) + "Delete Draft" (red bg)
4. Toast: "Draft deleted."

### 5-Stage Progress Bar (Order Tracking)

- 5 stages: Confirmed > Being Prepared > Out for Delivery > Delivered > Invoice Generated
- Completed stage: green filled circle (var(--color-success)) + connecting line solid green
- Current stage: blue pulsing ring (var(--color-primary), CSS pulse 2s infinite) + connecting line dashed
- Future stage: gray circle (var(--color-text-subtle)) + connecting line gray dashed
- Desktop: horizontal layout
- Mobile: horizontal, scrollable if needed
- Stage labels: Inter 400 12px below each circle

### GPS Delivery Map

- MapLibre GL wrapped in ClientOnly (non-negotiable)
- Driver position: blue dot (var(--color-primary)) with 12px radius + subtle pulse ring
- Route line: 3px blue polyline from driver to destination
- Destination: red pin (var(--color-error))
- ETA overlay: bottom-left card within map, Geist Mono 14px "ETA: 25 min"
- Map height: 300px desktop, 240px mobile, rounded-xl overflow hidden
- Arabic map labels via MapTiler
- Map updates: Supabase Realtime broadcast for GPS coordinates, smooth interpolation between points

### POD Confirm/Dispute Flow

1. After delivery, customer sees POD photos in tracking view
2. Banner: "Please confirm delivery within 72 hours" + countdown in Geist Mono
3. Two buttons: "Confirm Delivery" (green bg, 48px) + "Dispute" (red outline, 48px)
4. **Confirm:** POST confirmDropShipDelivery() > delivery transitions to "Delivered" > Toast "Delivery confirmed!"
5. **Dispute:** DisputeModal opens. Reason textarea (required) + photo upload (optional, max 5). "Go Back" (outline) + "Submit Dispute" (red bg). Creates support ticket.
6. After 72h without action: auto-confirmed by pg_cron (UI shows "Auto-confirmed" badge)

### Notifications Real-Time

- Supabase Realtime subscription on `notifications` table filtered by user_id
- New notification: spring animation at top of list (translateY from -20px, opacity 0 > 1, ~200ms)
- New notification triggers TanStack Query cache invalidation for unread count badge
- Click notification: marks read via PATCH markNotificationRead() + navigates to target entity + window closes
- Notification timestamp: Geist Mono 12px var(--color-text-subtle) (relative: "2 min ago", "1 hour ago", absolute after 7 days)
- "Show older" loads next 20 via cursor-based pagination

### Market Window Quick Add

- QuickAddToggle in toolbar: React Aria ToggleButton, text "Quick Add"
- When active: clicking any product card shows a Popover (React Aria Popover, CSS transition per UI-VISION) at the card
- Popover: product name, React Aria NumberField for quantity, UOM label, "Add" button (blue, 32px)
- On add: Toast "{Product} added to your quote." + Popover closes
- If no active draft exists: creates new draft automatically
- Infinite scroll: useInfiniteQuery with maxPages: 5, scroll sentinel at bottom, 2 skeleton cards appended while loading

### Filter Sidebar (Market Window)

- Desktop (>=1024px): sidebar within window, same as website market
- Narrow (<1024px): filter button in toolbar + React Aria Modal as bottom sheet (slide up from bottom, drag handle at top, tween 200ms)

### Settings Save Behavior

- Toggles and selects: save immediately on change (auto-save)
- Text fields: show "Save Changes" button (Inter 400 14px) when content differs from saved value
- Unsaved changes: warn on navigation away (beforeLoad prompt)
- Language change: applies immediately, page re-renders
- Theme change: applies immediately via data-theme attribute
- Number format toggle: only shown when Arabic locale selected

### Team Management

- Hidden-not-disabled rule: unauthorized elements are HIDDEN per UI-VISION
- Account owner sees full team table + "Invite Member" + role change + remove
- Non-owners see read-only team list (their own entry only visible)
- Invite flow: Dialog with phone + role Select (Buyer/Approver/Site Manager) > sends magic link
- Remove: confirmation modal with member name
- Transfer ownership: separate link, requires OTP confirmation modal

### Guest Claiming

- Triggered on signup when phone matches unclaimed customer record
- Banner at top of canvas (not a modal): "We found an existing account: A**** C****. Is this you?"
- "Yes, that's me" (blue bg) + "No, new account" (outline)
- On confirm: links auth user to existing customer, order history immediately visible
- Banner dismisses with tween 200ms slide up

### PWA Install

- localStorage visit counter incremented on portal load
- After 3rd visit: subtle banner at bottom of canvas (not blocking)
- Banner: "Install HyperQuote for faster access" + "Install" (blue bg, 32px) + dismiss X
- Push notification permission: requested on first notification-worthy action (order status change, quote ready, etc.), NOT on page load
- PushPermissionPrompt: React Aria Dialog. "Get notified about order updates?" + "Allow" (blue bg) + "Not now" (outline)

### Saved Lists & Favorites

- Saved lists appear as sub-section in Drafts tab
- SavedListCard: list name, item count (Geist Mono), last used (Geist Mono), "Reorder" (blue outline, 36px), "Edit" link
- FavoriteButton: Lucide Heart 16px, outline default, fill var(--color-error) when active (red fill -- exception to three-color rule, this is a data state per FRONTEND.md)
- "Favorites" filter chip in Market window toolbar

### AI Reorder Suggestion

- Contextual card above AI chat input (not a chat message)
- Background: var(--color-info-bg)
- Rounded-xl, p-12px
- "You ordered cement 30 days ago. Time to reorder?" + "Reorder" button (blue, 32px) + dismiss X (12px)
- Maximum 1 visible at a time
- Dismissed suggestions don't reappear for 7 days (localStorage cooldown)

## Accessibility Contract

- All modals use React Aria Dialog with `isKeyboardDismissDisabled`
- Tabs use React Aria Tabs with proper ARIA roles (tablist, tab, tabpanel)
- Notification list uses React Aria ListBox with aria-label "Notifications"
- Documents table uses React Aria Table with proper column headers
- Settings toggles use React Aria Switch with associated labels
- Radio groups (language, theme, number format) use React Aria RadioGroup
- GPS map: provide text alternative "Delivery tracking map" + ETA in text outside map
- Favorite toggle: aria-label "Add to favorites" / "Remove from favorites"
- Status badge colors are NEVER the only indicator -- always paired with text labels
- Focus management: modal open traps focus, modal close returns focus to trigger
- Date pickers use React Aria DatePicker with proper locale formatting
- File uploads provide progress indication and error feedback
- Team role select uses React Aria Select with proper label
- Draft card delete icon (Trash2): `aria-label="Delete draft {reference}"` where {reference} is the draft reference number (e.g., "Delete draft QR-2026-00042")
