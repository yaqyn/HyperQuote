    **lib/server/guest-claiming.ts:** Following isSupabaseConfigured pattern:
    - `checkUnclaimedCustomer`: GET, input { phone: z.string() }, returns { hasUnclaimed: boolean, maskedHint?: string (e.g. "A**** C****"), unclaimedCustomerId?: string }. Mock: returns { hasUnclaimed: true, maskedHint: "A**** C****", unclaimedCustomerId: "CUST-001" }.
