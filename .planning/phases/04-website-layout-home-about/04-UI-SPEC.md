## Spacing Scale

Declared values (multiples of 4, from tokens.css `--spacing: 0.25rem` base):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Right cluster gap, compact element spacing |
| md | 16px | Default element spacing, CTA horizontal padding |
| lg | 24px | Section internal padding |
| xl | 32px | Card padding (p-32px on value prop cards), layout gaps |
| 2xl | 48px | — |
| 3xl | 64px | Header height desktop, mobile section vertical padding (py-64px) |
| 4xl | 96px | Desktop section vertical padding (py-96px) |

Exceptions:
- Header height: 64px desktop, 56px mobile (56 = 14 * 4, valid)
- CTA button height: 56px on hero (14 * 4, valid), 36px on header (9 * 4, valid)
- Logo height: 28px (brand asset, not a spacing token)

## Typography

4 sizes, 2 weights. All other visual hierarchy achieved through color, opacity, spacing, and uppercase transforms.

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Display (hero headline) | 48px desktop / 20px mobile | 600 | 1.1 | Inter |
| Heading (section titles, error heading, how-it-works step title, card subheading) | 20px | 600 | 1.2 | Inter |
| Body (paragraphs, subheadlines, descriptions, CTA subtext, error body) | 16px | 400 | 1.5 (general) / 1.75 (about page prose) | Inter |
| Label (nav links, CTAs, footer links, column headings, language toggle, badges, trust bar) | 14px | 400 | 1.4 | Inter |

**Weight usage:**
- 400 (regular): Body text, labels, descriptions, subheadlines, trust bar, footer links
- 600 (semibold): All headings, display, CTAs, nav emphasis, column headings (uppercase), language toggle, team member names

**Numeric text:** Geist Mono at the same size/weight as the role it appears in (e.g. trust bar = 14px/400, step number = 48px/600, product count badge = 14px/400).

**Arabic constraint:** IBM Plex Sans Arabic caps at weight 700. Since the scale only uses 400 and 600, both are safe in bilingual contexts.

**Semantic colors used in this phase:**

## Animation Contract

| Element | Enter | Exit | Timing |
|---------|-------|------|--------|
| Hero headline | Spring: opacity 0->1, translateY 20->0, stiffness 120, damping 14 | n/a (page-level) | On load |
| Hero subheadline | Same spring | n/a | 100ms delay after headline |
| Hero CTA cluster | Same spring | n/a | 150ms delay after headline |
| Trust bar | Same spring | n/a | 200ms delay after CTAs |
| Scroll indicator | CSS bounce (infinite) | n/a | After trust bar |
| How-it-works cards | Spring: opacity 0->1, translateY 20->0 | n/a | IntersectionObserver 20%, stagger 100ms |
| Value prop cards | Same IntersectionObserver reveal | n/a | Stagger 100ms |
| Market preview cards | Same IntersectionObserver reveal | n/a | Stagger 100ms |
| Header blur | CSS transition (not Motion) | CSS transition | Trigger: scroll > 8px |
| Mobile nav overlay | Spring enter | Tween exit | React Aria Modal |
| Value prop card hover | translateY(-2px) + shadow-md | Return to rest | CSS transition |
| Market card hover | Image scale(1.03) | Return to rest | CSS transition |

## Interaction Contract

| Interaction | Component | Behavior |
|-------------|-----------|----------|
| Scroll past 8px | Header | Backdrop blur 12px + 80% opacity on `var(--color-base)` |
| Click logo | Header | Navigate to `/` |
| Click nav link | Header | Navigate to route, active state = blue text + 2px bottom border |
| Click language toggle | Header | Switch locale, flip `dir` on `<html>`, persist to localStorage |
| Click theme toggle | Header | Toggle `data-theme` on `<html>`, persist to localStorage |
| Click "Get a Quote" | Header CTA | If logged in -> portal. If not -> Login Modal (Phase 6). For now: link to portal URL. |
| Click hamburger (mobile) | Header | Open full-screen nav overlay (React Aria Modal, focus trapped) |
| Click scroll indicator | Hero | Smooth scroll to Section 2 |
| Click market category card | Market preview | Navigate to `/market?category={slug}` |
| Click "View All Products" | Market preview | Navigate to `/market` |
| Click "Get Started -- Free" | CTA section | Same as "Get a Quote" behavior |
| Click "Browse Market" | Hero | Navigate to `/market` |
| Click team member card | About | No action (informational) |
| Click "Careers" CTA | About | Navigate to `/careers` or `mailto:` |

## Accessibility Contract

| Element | Requirement |
|---------|-------------|
