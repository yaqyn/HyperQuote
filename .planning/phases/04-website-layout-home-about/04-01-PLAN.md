    The `beforeLoad` hook runs on the server. It must detect the user's locale from the request context:
    1. Read `hq-locale` cookie from the request headers (via `context.request?.headers?.get('cookie')` or Cloudflare Workers request object)
    2. Fall back to `Accept-Language` header parsing (check for `ar` in the header)
    3. Default to `'ar'` if neither is available (Arabic-first per brand)
    4. Pass the detected locale to `setupI18n(detectedLocale)` so i18n initializes with the correct language on the server
    5. Return `{ locale: detectedLocale }` from `beforeLoad` so the component can use `Route.useRouteContext()` to get the locale

    The `RootComponent` must:
    - Read the locale from route context (`Route.useRouteContext()`) for SSR, with `i18n.language` as client-side fallback
    - Set `lang` and `dir` on `<html>` from this server-resolved locale (NOT from `useTranslation()` alone, which may not be synced during SSR)
    - Add an inline `<script>` in `<head>` to prevent theme FOUC: `(function(){var t=localStorage.getItem('hq-theme');if(t)document.documentElement.setAttribute('data-theme',t);})()`
