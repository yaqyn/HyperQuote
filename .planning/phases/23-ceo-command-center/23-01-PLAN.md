Mock data: one detailed entity per type matching the CONTEXT.md Screen 4 example data exactly (Ahmed Fawzi for employee, Al-Masriya Construction for customer, ORD-1204 for order, INV-3892 for invoice, El-Nasr Steel for supplier, DEL-4521 for delivery, Portland Cement for product).

4. **server/digest.ts** -- Two server fns:

   - `getCEOWeeklyInsight({ weekOf: string })` returns insight with performanceSummary, keyObservations (3-4 strings), recommendedActions (action + entityType + entityId for routing).

Mock: returns static response with content text, optional chartData (SVG bar chart data), optional citations, optional entityLinks. Follow portal AG-UI mock pattern if exists, otherwise return plain response object.
