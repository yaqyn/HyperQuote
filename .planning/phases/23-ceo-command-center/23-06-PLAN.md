   - Import from workbox-precaching: `precacheAndRoute`.

   - Import from workbox-strategies: `StaleWhileRevalidate`, `CacheFirst`, `NetworkFirst`.
   - Import from workbox-expiration: `ExpirationPlugin`.

   - Precache app shell: `precacheAndRoute(self.__WB_MANIFEST);`
   - **Navigation requests**: `NetworkFirst` with 3s timeout fallback to cache (per RESEARCH.md Pitfall 5). Match: `({ request }) => request.mode === 'navigate'`.
   - **API responses**: `StaleWhileRevalidate` with 30min TTL for GET endpoints. Match: `({ url }) => url.pathname.startsWith('/api/')`.
   - **EXCLUDE `/_server` routes** from SW caching (per RESEARCH.md Open Question 3). TanStack Start server functions use POST to `/_server`.
   - **Fonts**: `CacheFirst` with 1-year TTL, max 10 entries. Match: `({ request }) => request.destination === 'font'`.
   - **Images**: `CacheFirst` with 7-day TTL. Match: `({ request }) => request.destination === 'image'`.
   - Skip waiting + claim clients on install for immediate activation.

   - Schema `CEOOfflineDB`:
     - `digest`: key=string (date), value={ date, data, syncedAt }
     - `insight`: key=string (weekOf), value={ weekOf, data, syncedAt }
     - `attention`: key='current', value={ items[], syncedAt }
     - `entities`: key=string (`${type}-${id}`), value={ type, id, data, syncedAt }, index: `by-type`
     - `searches`: key=string (query), value={ query, results, syncedAt }
   - Export `getOfflineDB()` function.
   - Export helpers: `cacheEntity(type, id, data)`, `getCachedEntity(type, id)`, `cacheSearchResults(query, results)`, `getCachedSearch(query)`, `cacheAttentionItems(items)`, `getCachedAttentionItems()`, `cacheDigest(date, data)`, `getCachedDigest(date)`.
   - Each cache function stores `syncedAt: Date.now()`.

     ```typescript

     // Step 1: Compile sw.ts to JS
     await Bun.build({ entrypoints: ['src/sw.ts'], outdir: '.tmp', target: 'browser' });
     // Step 2: Inject manifest
     const { count, size } = await injectManifest({
       swSrc: '.tmp/sw.js',
       swDest: 'dist/client/sw.js',
       globDirectory: 'dist/client',
       globPatterns: ['**/*.{js,css,html,woff2,png,svg}'],
       maximumFileSizeToCacheInBytes: 5 * 1024 * 1024,
     });
     console.log(`Generated SW: ${count} files, ${(size / 1024).toFixed(1)}KB`);
     ```
