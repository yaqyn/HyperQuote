1. **search.tsx route** --
   - URL: `/_ceo/search` with `validateSearch` using `z.object({ q: z.string().optional() })`.
   - Route loader: calls `searchEntities({ query: q })` with debounce handled client-side.
   - Component: Search bar at top (slides up from center position -- reuse SearchBar component), results stream below.
   - If `q` is empty, show empty state or redirect back to home.
   - Per CONTEXT.md: Enter/Send on a result transitions to AI chat. Escape -> back to home.
   - The search bar from home is now pinned to the top of the viewport.

2. **SearchResults.tsx** -- Container that maps over `SearchResultGroup[]`.
   - Renders `EntityGroup` for each group that has results.
   - Groups ordered by relevance score (server-sorted), not fixed order.
   - Empty state: "No results found for '{query}'" with suggestion to try AI chat.
   - 150ms debounce on input changes before fetching (use `useDeferredValue` or setTimeout in onChange).

3. **EntityGroup.tsx** -- Single entity type group.
   - Header: entity type label in Inter 500, text-sm, uppercase, tracking-wide, muted gray. Like: "CUSTOMERS", "ORDERS".
   - Shows top 3 results as `SearchResultRow`.
   - "View all ({total})" link if total > 3. Inter 400, text-sm, muted gray. No blue.
   - Collapsible via Enter on header (per CONTEXT.md keyboard nav).
   - Tab key jumps between group headers.

4. **SearchResultRow.tsx** -- Individual result row.
   - Title: Inter 500, text-base, text-[var(--color-text)]
   - Subtitle: Inter 400, text-sm, text-[var(--color-text-muted)]
   - Score indicator: not shown to user, but used for ordering.
   - Click or Enter -> navigate to `/entity/${type}/${id}`.
   - Arrow keys (Up/Down) move between rows across all groups.
   - Hover: `bg-[var(--color-surface)]` subtle highlight. NO blue highlight.
   - Exact match shortcut: if single result with score > 0.95, auto-navigate to detail.

5. **Keyboard navigation**: Manage focus with `tabIndex` and `onKeyDown`. Arrow keys move focus between rows. Tab jumps between group headers. Enter opens detail or toggles group collapse.

   - Params: `type` (EntityType) and `id` (string).
   - Loader: calls `getEntityDetail({ entityType: type, entityId: id })`.
   - Component: Switch on `type` to render the correct entity detail component, all wrapped in `DetailView` layout.
   - Back navigation: `router.history.back()` or navigate to previous search results (preserving search state).

2. **DetailView.tsx** -- Shared layout wrapper per RESEARCH.md Pattern 2:
   - Props: `title` (Inter 600, text-xl), `subtitle` (Inter 400, text-base, muted), `onBack`, `deepLinkUrl?`, `deepLinkLabel?`, `actions?` (ReactNode), `children` (ReactNode).
   - Layout: `p-6 max-w-2xl mx-auto`
   - Back button: `<button>` with `ArrowLeft` icon from lucide-react. NO blue. `text-[var(--color-text)]`.
   - Deep link: "View full details in {Module} -->" as muted gray text at bottom.
   - Action buttons: text-only, Inter 500, no background, 24px spacing. NO blue. `text-[var(--color-text)] font-medium`.

3. **DetailSection.tsx** -- Reusable section within detail views.
   - Props: `label: string`, `children: ReactNode`
   - Label: Inter 500, text-sm, uppercase, tracking-wide, muted gray.
   - 24px vertical spacing between sections.

4. **EmployeeDetail.tsx** -- Per CONTEXT.md Screen 4:
   - Subtitle: "{role} -- {department}" then "Joined: {date}" (Geist Mono 400 for date).
   - Contact section: phone with [Call] (tel: link), email with [Email] (mailto: link).
   - Quick stats: 4 stats in a 2-col grid. Labels Inter 400, values Geist Mono 500.
   - Recent activity: last 5 entries, date in Geist Mono 400, description in Inter 400.
   - Deep link: "View full profile in HR -->"

5. **CustomerDetail.tsx** -- Per CONTEXT.md:
   - Contact section with primary contact, account manager.
   - Financial snapshot: credit limit, credit used with utilization percentage (Geist Mono). Utilization bar: gray background, gray fill. >80% = `var(--color-warning)` fill, >95% = `var(--color-error)` fill. Total AR, overdue amount with semantic error badge if overdue.
   - Order history: 4 stats (orders count, total revenue, avg order value, avg margin) all Geist Mono.
   - Recent orders: list with reference, amount (Geist Mono), status badge.
   - Alerts: bounced cheque with error color.
   - Actions: [Route to Finance], [Route to Sales], [Call Account Manager].
   - Deep link: "View full profile in CRM -->"

6. **OrderDetail.tsx** -- Items list, financial section (value, margin, invoice ref, payment status with warning/error badges, outstanding), delivery info, timeline. Deep link to Orders.

7. **InvoiceDetail.tsx** -- Amount, VAT (14%), total all in Geist Mono 500. Payment status, outstanding, days until due. ETA submission info. Deep link to Finance.

8. **SupplierDetail.tsx** -- Contact, performance stats (Geist Mono), terms. Deep link to Procurement.

9. **DeliveryDetail.tsx** -- Status badge, driver, vehicle, timeline (times in Geist Mono 400), items delivered (with SHORT notation for discrepancies), POD info. Deep link to Logistics.

10. **ProductDetail.tsx** -- Pricing (internal-only label), movement stats, availability with suppliers list. Deep link to Products.

ALL monetary values: use `CurrencyDisplay` from @hyperquote/ui or `Intl.NumberFormat('ar-EG', { style: 'currency', currency: 'EGP' })` with Geist Mono font. ALL dates: Geist Mono 400. ALL percentages: Geist Mono. Status badges: use `StatusBadge` from @hyperquote/ui with semantic colors only.
