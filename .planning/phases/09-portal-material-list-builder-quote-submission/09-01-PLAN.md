**1. Server functions** (`apps/portal/src/lib/server/quote-requests.ts`):
- `submitQuoteRequest` -- createServerFn().inputValidator(z.object({...})).handler(async ({data: input}) => {...})
  - Auth check via getServerSession (same pattern as chat.ts)
  - Dev mode fallback if Supabase not configured (return mock { requestId, reference })
  - Insert quote_request + quote_request_items in transaction
  - If approval_required: insert approval record, set status to 'draft'
  - Else: set status to 'submitted', set submitted_at
  - Return { requestId: string, reference: string }
  - Include idempotencyKey in input schema (z.string().uuid())

- `saveDraft` -- save/update draft quote_request with status 'draft'
  - Upsert: if draftId provided, update; else insert new
  - Return { draftId: string }

- `getDrafts` -- fetch user's draft quote_requests with items
  - Return array of drafts with items

- `parseWithAI` -- accepts { text: string }, returns { parsedItems: ParsedRow[] }
  - Mock implementation: keyword matching for common building materials (cement, rebar, plywood, etc.)
  - Returns structured items with matchConfidence
  - Phase 30 swaps with real AI

**2. Server functions** (`apps/portal/src/lib/server/addresses.ts`):
- `getCustomerAddresses` -- fetch addresses for current customer
- `createAddress` -- insert new address, return it
- `getCustomerProjects` -- fetch projects for current customer
- `createProject` -- insert new project, return it

**3. Server functions** (`apps/portal/src/lib/server/products-search.ts`):
- `searchProducts` -- accepts { query: string, limit?: number }
  - Uses tsvector full-text search on products table
  - Returns products with PUBLIC_COLUMNS only (never cost fields)
  - PUBLIC_COLUMNS whitelist: id, sku, slug, name, name_ar, category, unit_of_measure, price_range_min, price_range_max, availability_status, image_urls

**4. Zustand store** (`apps/portal/src/stores/quote-builder.ts`):
- QuoteItem type: { id, productId?, customerDescription, quantity, unitOfMeasure, notes?, matchConfidence?, sortOrder, isUnmatched }
- Store state: step (1|2|3), items: QuoteItem[], draftId?, projectId?, deliveryAddressId?, deliveryDate?, notes, attachments: File[], isDirty
- Actions: setStep, addItem, removeItem, updateItem, reorderItems, setItems, setProjectId, setDeliveryAddressId, setDeliveryDate, setNotes, setAttachments, reset
- Use Zustand persist middleware with localStorage and skipHydration: true (SSR safe, pattern from chat.ts)
- Key: 'quote-draft'

**5. Auto-save hook** (`apps/portal/src/hooks/useQuoteDraft.ts`):
- useQuoteDraft hook: 30-second interval saves store state to localStorage
- On mount: check localStorage for existing draft, compare timestamps, restore newer
- Also debounced server save (5s after last change) via saveDraft server function
- Return { isRestoring, hasDraft, clearDraft }

**6. File parser** (`apps/portal/src/lib/file-parser.ts`):
- parseCSV(file: File): Promise<ParseResult> -- uses PapaParse with { header: true, skipEmptyLines: true, dynamicTyping: false }
- parseExcel(file: File): Promise<ParseResult> -- uses SheetJS XLSX.read + sheet_to_json
- detectFileType(file: File): 'csv' | 'xlsx' | 'unknown'
- ParseResult type: { items: ParsedRow[], errors: ParseError[], totalRows: number }
- ParsedRow: { productName?, sku?, quantity?, uom?, notes?, rowNumber }
- ParseError: { rowNumber, field, value, expected }
- Handle Arabic column headers (اسم المنتج, الكمية, الوحدة, ملاحظات)
- Handle UTF-8 BOM, auto-detect delimiters (PapaParse handles this)

**7. Business days** (`apps/portal/src/lib/business-days.ts`):
- isEgyptianBusinessDay(date: DateValue): boolean -- uses isWeekend from @internationalized/date with 'ar-EG' locale
- Always pass 'ar-EG' locale regardless of user's display locale (Friday + Saturday are weekend)
- Egyptian public holidays 2026 list (approximate dates for Eid al-Fitr, Eid al-Adha, Revolution Day, etc.)
- isDateUnavailable(date: DateValue): boolean -- combines weekend + holiday check
- getNextBusinessDay(from: DateValue): DateValue

**8. Product search hook** (`apps/portal/src/hooks/useProductSearch.ts`):
- useProductSearch(query: string) hook
- Loads first 500 products into fuse.js index on first search (via TanStack Query with staleTime 5min)
- Client-side fuse.js search with 150ms debounce
- If no results found client-side, fall back to server searchProducts function
- Returns { results: Product[], isLoading }

**9. Submit hook** (`apps/portal/src/hooks/useQuoteSubmit.ts`):
- useQuoteSubmit() hook wrapping TanStack Query useMutation
- Calls submitQuoteRequest server function
- On success: clears draft from localStorage and store, returns reference
- On error: returns error message for toast
