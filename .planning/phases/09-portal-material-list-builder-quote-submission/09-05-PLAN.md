**1. Create approvals.ts server functions:**
- `submitForApproval` -- createServerFn().inputValidator(z.object({...})).handler(async ({data: input}))
  - Same input as submitQuoteRequest but sets approval_required = true, status stays 'draft'
  - Creates approval record: entity_type = 'quote_request', entity_id = quote_request.id, requested_by = current user, assigned_to = team approver
  - Dev mode fallback: return mock { requestId, reference, approvalId }
  - Finding the approver: query user_profiles + user_roles where customer_id matches and role includes 'approver'. If no approver found, submit directly (bypass approval).

- `getPendingApprovals` -- fetch approval records where assigned_to = current user, status = 'pending', entity_type = 'quote_request'
  - Join with quote_requests and quote_request_items for display data
  - Return: array of { approvalId, quoteRequest: { id, reference, itemCount, requestedBy: { name }, createdAt } }

- `approveQuoteRequest` -- input: { approvalId: string }
  - Update approval status to 'approved', set decided_at
  - Update quote_request: status -> 'submitted', submitted_at -> now(), approval_required stays true, approved_by = current user
  - Return { success: true }

- `requestChanges` -- input: { approvalId: string, notes?: string }
  - Update approval status to 'changes_requested', set decided_at, set notes
  - Update quote_request: approval_notes = notes
  - Return { success: true }

**2. Create useApproval.ts hook:**
- `useIsApprover()`: checks if current user's roles include 'approver'. Returns boolean.
  - Use auth session from route context (already loaded by _portal.tsx beforeLoad)
  - For dev mode: check localStorage flag 'dev-is-approver' for testing
- `useNeedsApproval()`: checks if current user is NOT an approver AND their team HAS an approver. Returns boolean.
  - If true, submit should go through approval workflow
  - If false (solo account or user IS the approver), submit directly

**3. Update ReviewStep.tsx:**
- Import useNeedsApproval hook
- If needsApproval is true:
  - Change button text to t('quoteBuilder.submitForApproval') -- "Submit for Approval"
  - Change confirmation modal text to t('quoteBuilder.confirmApproval') -- "Submit for approval? Your team approver will review this request."
  - On confirm: call submitForApproval instead of submitQuoteRequest
- If needsApproval is false: existing behavior (direct submit)

**4. Update SubmitConfirmation.tsx:**
- Accept `isApproval` prop
- If isApproval:
  - Heading: t('quoteBuilder.approvalSuccessHeading') -- "Submitted for Approval!"
  - Body: t('quoteBuilder.approvalSuccessBody') -- "Your approver will be notified."
  - No "Track Quote" button (quote isn't submitted yet)
  - "Back to Orders" link
- If not approval: existing success view
