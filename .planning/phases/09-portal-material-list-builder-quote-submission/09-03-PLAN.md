**1. Create QuickPad.tsx:**
- Spreadsheet-style grid for power users
- 3 columns: SKU/name input (React Aria ComboBox, 60% width) + Quantity input (React Aria NumberField, 20% width) + UOM display (20% width, auto-populated, read-only)
- 10 empty rows shown by default. As user fills rows, more empty rows appear at bottom (always maintain 3 empty rows below last filled).
- Tab key flow: SKU ComboBox -> auto-populate name/unit -> Qty NumberField -> next row's SKU ComboBox (skip auto-populated UOM)
- Shift+Tab reverses order
- Enter: adds one valid item to the product list table (copies from quick pad to store)
- Ctrl+Enter: adds ALL valid items at once
- SKU ComboBox: reuses useProductSearch for search. On select: auto-populate product name in display, set UOM, keep focus flow.
- SKU validation: 300ms debounce. Invalid SKU: red border (var(--color-error)) + inline error text 12px var(--color-error)
- Multi-SKU paste support: detect paste event on SKU ComboBox. If pasted text contains newlines or tabs, split into rows and fill subsequent empty rows.
- Each row: h-44px, border-bottom 1px var(--color-border)
- Mobile: single-row input mode. One row visible at a time with Next/Previous navigation buttons (h-36px, outline).
