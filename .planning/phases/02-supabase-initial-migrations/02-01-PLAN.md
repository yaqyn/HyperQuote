Create `supabase/migrations/20260331000003_auth_tables.sql` with all 7 tables in dependency order:

**1. tenants** -- exactly as in CONTEXT.md:
- UUID PK with `gen_random_uuid()`
- `inventory_costing_method` typed as `inventory_costing_method NOT NULL DEFAULT 'wac'`
- `currency TEXT DEFAULT 'EGP'`, `timezone TEXT DEFAULT 'Africa/Cairo'`
- `tax_id TEXT`, `commercial_register TEXT`, `tax_registration_number TEXT`

**2. employees** -- after tenants (references tenants):
- UUID PK, `tenant_id UUID NOT NULL REFERENCES tenants(id)`
- `reports_to UUID REFERENCES employees(id)` (self-reference)
- `cdl_class egyptian_license_class` (uses enum from migration 002)
- `UNIQUE (tenant_id, employee_number)`
- Egyptian-specific: `social_insurance_salary DECIMAL(15,2)`, `first_name_ar TEXT`, `last_name_ar TEXT`

**3. user_profiles** -- after tenants and employees:
- UUID PK, `user_id UUID UNIQUE NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE`
- `tenant_id UUID NOT NULL REFERENCES tenants(id)`
- `user_type user_type NOT NULL` (uses enum)
- **ADD `pool TEXT NOT NULL DEFAULT 'external' CHECK (pool IN ('internal', 'external'))`** -- missing from CONTEXT.md table def but required by custom_access_token_hook
- `customer_id UUID` -- NO FK constraint (deferred to Phase 13, table doesn't exist yet)
- `supplier_id UUID` -- NO FK constraint (deferred to Phase 13)
- `driver_id UUID` -- NO FK constraint (deferred to Phase 13)
- `employee_id UUID REFERENCES employees(id)` -- employees exists in this migration
- `display_name TEXT GENERATED ALWAYS AS (first_name || ' ' || last_name) STORED`
- Add COMMENTs on customer_id, supplier_id, driver_id explaining deferred FKs

**4. user_roles** -- after user_profiles:
- `BIGINT GENERATED BY DEFAULT AS IDENTITY` PK
- `user_id UUID NOT NULL REFERENCES auth.users(id) ON DELETE CASCADE`
- `role app_role NOT NULL`
- `tenant_id UUID NOT NULL REFERENCES tenants(id)`
- `UNIQUE (user_id, role, tenant_id)`

**5. role_permissions**:
- `BIGINT GENERATED BY DEFAULT AS IDENTITY` PK
- `role app_role NOT NULL`, `permission app_permission NOT NULL`
- `UNIQUE (role, permission)`

**6. approvals** -- uses approval_type and approval_status enums:
- UUID PK, `tenant_id UUID NOT NULL REFERENCES tenants(id)`
- `requested_by UUID NOT NULL REFERENCES auth.users(id)`, `assigned_to UUID NOT NULL REFERENCES auth.users(id)`
- `escalated_to UUID REFERENCES auth.users(id)`
- `context JSONB DEFAULT '{}'`

**7. audit_log** -- partitioned by month:
- `BIGINT GENERATED ALWAYS AS IDENTITY`
- `PRIMARY KEY (created_at, id)` -- composite PK required for partitioning
- `PARTITION BY RANGE (created_at)`
- Create 4 partitions: audit_log_2026_04, _2026_05, _2026_06, _2026_07

**Indexes** (for RLS performance):
- `CREATE INDEX idx_user_profiles_user_id ON user_profiles(user_id);`
- `CREATE INDEX idx_user_profiles_tenant_id ON user_profiles(tenant_id);`
- `CREATE INDEX idx_user_profiles_customer_id ON user_profiles(customer_id);`
- `CREATE INDEX idx_user_profiles_supplier_id ON user_profiles(supplier_id);`
- `CREATE INDEX idx_user_profiles_driver_id ON user_profiles(driver_id);`
- `CREATE INDEX idx_user_roles_user_id ON user_roles(user_id);`
- `CREATE INDEX idx_user_roles_tenant_id ON user_roles(tenant_id);`
- `CREATE INDEX idx_employees_tenant_id ON employees(tenant_id);`
- `CREATE INDEX idx_employees_user_id ON employees(user_id);`
- `CREATE INDEX idx_approvals_tenant_id ON approvals(tenant_id);`
- `CREATE INDEX idx_approvals_assigned_to ON approvals(assigned_to);`
- `CREATE INDEX idx_approvals_entity ON approvals(entity_type, entity_id);`
- `CREATE INDEX idx_audit_log_tenant_id ON audit_log(tenant_id);`
- `CREATE INDEX idx_audit_log_user_id ON audit_log(user_id);`
- `CREATE INDEX idx_audit_log_entity ON audit_log(entity_type, entity_id);`

**RLS** -- enable on all 7 tables. For this phase, add basic tenant isolation policies:
- tenants: `USING (id = (SELECT public.current_tenant_id()))` for authenticated
- user_profiles: `USING (tenant_id = (SELECT public.current_tenant_id()))` for authenticated
- user_roles: `USING (tenant_id = (SELECT public.current_tenant_id()))` for authenticated
- role_permissions: `USING (true)` for authenticated (readable by all, no tenant scoping)
- employees: `USING (tenant_id = (SELECT public.current_tenant_id()))` for authenticated
- approvals: `USING (tenant_id = (SELECT public.current_tenant_id()))` for authenticated
- audit_log: `USING (tenant_id = (SELECT public.current_tenant_id()))` for authenticated

Note: RLS policies reference `current_tenant_id()` which is created in Plan 02 (migration 004). The policies will exist but won't be testable until Plan 02 completes. This is fine -- `supabase db reset` applies all migrations in order.

**updated_at triggers**: attach `update_updated_at()` trigger to tenants, user_profiles, employees, approvals. The trigger function is created in Plan 02 migration 004, but the trigger attachment goes here with the table definition. Since migrations run in order, migration 004 creates the function before these triggers fire. However, the trigger CREATE statements reference the function -- so move the trigger attachments to migration 004 instead. Add a comment in this migration: `-- updated_at triggers attached in migration 004 after function creation`.
