    Build ALL 12 components following research patterns. Key implementation details:

    **Glass components:**

    1. `GlassWindow.tsx` — Spring enter, tween exit. Two tiers. Per DS.6:
       - Props: `isOpen: boolean`, `onClose: () => void`, `children: ReactNode`, `className?: string`
       - Use `motion.div` from `motion/react` with `AnimatePresence`
       - Enter: `type: 'spring', stiffness: 200, damping: 20`
       - Exit: `transition: { duration: 0.2, ease: 'easeIn' }` (tween)
       - Window tier: `backdrop-blur-xl bg-[rgba(255,255,255,0.80)]` light, `dark:bg-[rgba(0,0,0,0.80)]` dark
       - Desktop: `w-[90vw] h-[90vh]`. Mobile: `max-md:w-full max-md:h-full`
       - Shadow: `shadow-md`
       - CRITICAL: Use `dark:` variant via the `@custom-variant` (data-theme attribute, not class)

    2. `GlassElevated.tsx` — Same animation pattern, elevated tier:
       - `backdrop-blur-2xl bg-[rgba(255,255,255,0.90)]` / dark: `bg-[rgba(0,0,0,0.90)]`
       - `shadow-lg`, z-50 (above GlassWindow at z-40)
       - Used for modals, confirmations, command palette

    **Display components (all use Geist Mono for numbers = `font-mono` class):**

    3. `CurrencyDisplay.tsx`:
       - Props: `value: number`, `currency?: string` (default 'EGP')
       - Use `useTranslation()` from react-i18next for locale detection
       - Use `Intl.NumberFormat` with locale 'ar-EG' or 'en-EG' + `{ style: 'currency', currency: 'EGP' }`
       - Wrap output in `<span className="font-mono">`
       - Cache formatters as module-level constants (not recreated per render)

    4. `DateDisplay.tsx`:
       - Props: `date: Date | string`, `format?: 'short' | 'medium' | 'long'` (default 'medium')
       - Use `useTranslation()` for locale
       - Use `Intl.DateTimeFormat` with appropriate options per format
       - Wrap in `<span className="font-mono">` for the date output

    5. `UnitDisplay.tsx`:
       - Props: `value: number`, `unit: string` (UnitOfMeasure enum key)
       - Use `useTranslation('units')` to get unit translation
       - Number in `<span className="font-mono">`, unit in `<span>` (separate elements per DS.9)
       - Uses `Intl.NumberFormat` for number part
