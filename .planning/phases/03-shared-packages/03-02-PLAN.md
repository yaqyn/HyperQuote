       - Props: `isOpen: boolean`, `onClose: () => void`, `children: ReactNode`, `className?: string`
       - Use `AnimatePresence` from `motion/react`
       - Spring ENTER: `initial={{ opacity: 0, scale: 0.95 }}`, `animate={{ opacity: 1, scale: 1 }}`, `transition={{ type: 'spring', stiffness: 200, damping: 20 }}`

       - WAIT: Tailwind v4 with `@custom-variant dark (...)` replaces the default `dark:` variant. So `dark:` classes WILL use `data-theme`. This is correct.
       - Size: `w-[90vw] h-[90vh]` desktop, `w-full h-full` on mobile (max-md)
       - Shadow: `shadow-md` (per DS.18)
       - Rounded: `rounded-xl`
       - Overflow: `overflow-auto`
