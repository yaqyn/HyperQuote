# Phase 8 — UI Design Contract

> Visual and interaction contract for Portal AI Chat: streaming chat with rich messages, slash commands, quick action chips, conversation history, voice input, file upload, supplier mode AI. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn excluded per CLAUDE.md -- React Aria mandated) |
| Preset | not applicable |
| Component library | React Aria Components ^1.16.0 |
| Icon library | Lucide React |
| Font | Inter (Latin), IBM Plex Sans Arabic (Arabic), Geist Mono (all numbers) |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline element padding, chip internal gap |
| sm | 8px | Message bubble internal gap, chip outer gap, compact spacing |
| md | 16px | Message bubble padding, card padding, section gaps |
| lg | 24px | Chat area horizontal padding, history overlay padding |
| xl | 32px | Major layout gaps |
| 2xl | 48px | Page-level vertical padding |
| 3xl | 64px | Not used in this phase |

Exceptions: 44px minimum touch target for all buttons (send, stop, mic, attach, chip taps, history entries). 56px main AI chat input height (carried from Phase 7). 44px compact chat input height (floating AI panel). 48px product card image size. 32px action button height. 640px chat input max-width. 380px floating AI panel width. 60vh floating AI panel max-height. 12px message bubble horizontal margin from edge. 20px chat input horizontal padding (carried from Phase 7).

## Typography

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body / Message text | 14px | 400 | 1.5 | Inter / IBM Plex Sans Arabic |
| Small / Meta / Timestamp | 12px | 400 | 1.5 | Inter / IBM Plex Sans Arabic |
| Heading (history group, card title) | 16px | 600 | 1.2 | Inter / IBM Plex Sans Arabic |
| Numbers (prices, order IDs, quantities) | 14px | 400 | 1.5 | Geist Mono |

Distinct sizes: 12px, 14px, 16px (3 sizes, 2 weights: 400 + 600).

Notes:
- Portal base is 14px (not 16px -- website-only per UI-VISION.md).
- Geist Mono for ALL numeric data in AI responses: order numbers, prices, quantities, dates.
- Arabic-Indic numerals when locale is Arabic. No exceptions.
- Message text renders markdown: bold (**), italic (*), inline code. No h1-h6 in messages.
- Typing indicator uses 12px 400 `var(--color-text-muted)`.

Glass surfaces (carried from Phase 7):

- Green `var(--color-success)`: delivered, confirmed statuses in status cards

## Component Inventory

### 1. Chat Message Area (upgrades Phase 7 plain text)
- Scrollable area above input, grows upward as messages accumulate
- Scroll-to-bottom on new message. Show "scroll to bottom" pill when scrolled up.
- Padding: px-24px (desktop), px-16px (mobile)
- Max-width: 640px centered (matches input width)

### 2. User Message Bubble
- `var(--color-primary)` bg, white text, rounded-2xl, rounded-br-md (rounded-bl-md in RTL)
- Max-width: 80% of chat area
- Padding: 12px 16px
- Aligned inline-end (right in LTR, left in RTL)
- Font: Inter 400 14px, line-height 1.5
- Timestamp: 12px `var(--color-text-muted)` below bubble, opacity 0.6

### 3. AI Message Bubble
- `var(--color-card)` bg, border 1px `var(--color-border)`, rounded-2xl, rounded-bl-md (rounded-br-md in RTL)
- Max-width: 85% of chat area
- Padding: 16px
- Aligned inline-start (left in LTR, right in RTL)
- Font: Inter 400 14px, line-height 1.5
- Streaming: text appears word-by-word (token-by-token from SSE)
- Structured content (cards, tables, buttons) buffers until complete, then appears with spring animation
- Timestamp: 12px `var(--color-text-muted)` below bubble

### 4. Product Card (inline in AI messages)
- Compact horizontal layout: image 48x48px rounded-lg + content area
- Content: product name (14px 600), specs summary (12px 400 muted), price range (Geist Mono 14px 400)
- "Add to Quote" button: blue outline, h-32px, 12px 600 text, rounded-lg
- Border: 1px `var(--color-border)`, rounded-xl, p-12px, mt-8px between cards
- Multiple product cards stack vertically with 8px gap

### 5. Status Card (inline in AI messages)
- Order/quote number: Geist Mono 14px 600
- Status badge: 12px 600, semantic color bg at 10% opacity + text color, rounded-full, px-8px py-2px
- Key dates: 12px 400 muted, Geist Mono for date values
- Border: 1px `var(--color-border)`, rounded-xl, p-12px
- Optional: mini progress indicator (5 dots for order stages, filled up to current)

### 6. Action Buttons (inline in AI messages)
- Blue outline buttons: border 1px `var(--color-primary)`, text `var(--color-primary)`, h-32px, rounded-lg, px-12px
- Font: 12px 600
- Horizontal row with 8px gap, wrap to next line on overflow
- Examples: "Create Quote", "Track Order #847", "View Invoice"
- On click: navigate to relevant portal route or trigger portal action

### 7. Estimation Disclaimer Block
- Yellow-tinted card: `var(--color-warning)` bg at 5% opacity, border 1px `var(--color-warning)` at 20% opacity
- Icon: AlertTriangle (Lucide) 16px `var(--color-warning)` at inline-start
- Text: 12px 400 `var(--color-text)`, line-height 1.5
- EN: "This is an AI estimate. Verify quantities with your engineer before ordering."
- AR: "هذا تقدير ذكاء اصطناعي. تحقق من الكميات مع مهندسك قبل الطلب."
- Rendered below AI-generated material lists, always. Non-dismissible.

### 8. Quick Action Chips (below chat input)
- Horizontal scrollable row, gap-8px, mt-8px below input
- Each chip: h-32px, rounded-full, border 1px `var(--color-border)`, px-12px
- Font: 12px 400 `var(--color-text)`
- Hover: border-color `var(--color-primary)`, text-color `var(--color-primary)`
- Home state chips: "Get a quote" | "Track my order" | "Check prices" | "Upload material list"
- Post-product discussion chips: "Add to quote" | "Check stock" | "See alternatives" | "Compare prices"
- Chips change contextually based on conversation stage (Zustand state)
- AR chips: "احصل على عرض سعر" | "تتبع طلبي" | "تحقق من الأسعار" | "ارفع قائمة المواد"
- Post-product AR: "أضف للعرض" | "تحقق من التوفر" | "شاهد البدائل" | "قارن الأسعار"

### 9. Slash Command Palette
- Triggers when user types `/` at start of input
- Elevated glass overlay above input: `backdrop-blur-2xl bg-[rgba(255,255,255,0.90)] dark:bg-[rgba(0,0,0,0.90)]`
- Rounded-xl, shadow-lg, max-width matches input (640px), p-4px
- 4 commands: `/quote`, `/track`, `/price`, `/help`
- Each item: h-40px, px-12px, rounded-lg, hover bg `var(--color-primary)` at 5%
- Active item: bg `var(--color-primary)` at 10%, text `var(--color-primary)`
- Icon (20px) + command name (14px 600) + description (14px 400 muted)
- Arrow key navigation + Enter to select + Escape to dismiss
- Autocomplete filters as user types after `/`

| Command | Icon | Description EN | Description AR |
|---------|------|---------------|---------------|
| `/quote` | FileText | "Start a new quote request" | "ابدأ طلب عرض سعر جديد" |
| `/track` | MapPin | "Track an order or delivery" | "تتبع طلب أو توصيل" |
| `/price` | DollarSign | "Check product prices" | "تحقق من أسعار المنتجات" |
| `/help` | HelpCircle | "Get help and support" | "احصل على المساعدة والدعم" |

### 10. Conversation History Overlay
- Triggered by History icon button (Lucide `History`, 20px) positioned above chat input area, inline-end
- Elevated glass overlay: full viewport on mobile, 480px wide anchored center on desktop
- Max-height: 80vh, rounded-2xl (desktop), full-screen (mobile)
- Header: "Chat History" / "سجل المحادثات" (16px 600) + close button (X, 44px touch target)
- Search input: h-40px, rounded-xl, border 1px, placeholder "Search conversations..." / "ابحث في المحادثات..."
- Grouped by date: "Today" / "اليوم", "Yesterday" / "أمس", "This Week" / "هذا الأسبوع", month names
- Group header: 12px 600 `var(--color-text-muted)`, uppercase, ps-16px
- Each thread entry: h-64px, px-16px, hover bg `var(--color-primary)` at 3%
  - First message preview: 14px 400, single line truncated
  - Key entity tag: Geist Mono 12px, e.g. "Quote #2026-00042" or "Order #847"
  - Relative time: 12px 400 muted, inline-end
- Pin icon on long-press (mobile) or right-click (desktop): toggles pin
- Pinned conversations: separate "Pinned" / "مثبتة" section at top
- Click thread: overlay closes, chat loads that conversation thread
- Empty state: "No conversations yet" / "لا توجد محادثات بعد"

### 11. Typing Indicator
- Displayed when AI is processing (before first token arrives)
- "HyperQuote is thinking..." / "هايبر كوت يفكر..." -- Inter 400 12px `var(--color-text-muted)`
- 3-dot bounce animation (CSS keyframes, not Motion): dots at 4px diameter, 4px gap, 600ms cycle staggered 200ms
- Positioned inline-start, same alignment as AI messages

### 12. Stop/Cancel Button
- While streaming: send button morphs to stop button
- Square icon (Lucide `Square`), 16px, `var(--color-error)` tint
- Same 40px circle, bg `var(--color-error)` at 10%, border 1px `var(--color-error)` at 20%
- Click triggers AbortController to cancel SSE stream
- After cancellation: partial AI response stays visible, "(Stopped)" / "(تم الإيقاف)" label appended in 12px muted

### 13. Voice Input Button (progressive enhancement)
- Position: inline-end of chat input, before send button (between attach and send)
- Lucide `Mic` icon, 20px, `var(--color-text-muted)`
- 44px touch target
- Hidden if Web Speech API not supported (feature detect `window.SpeechRecognition || window.webkitSpeechRecognition`)
- Active state: Mic icon turns `var(--color-error)` (red = recording), pulsing ring animation (CSS)
- Waveform indicator: 3 animated bars replacing the Mic icon during recording (CSS keyframes)
- Transcribed text fills input field for review before sending
- Language detection: `ar-EG` for Arabic locale, `en-US` for English

### 14. File Attachment Button
- Position: inline-end of chat input, before mic button
- Lucide `Paperclip` icon, 20px, `var(--color-text-muted)`
- 44px touch target
- Opens native file picker: accept images (JPG, PNG), PDFs, CSVs, Excel (XLSX)
- Size limit: 10MB. Show error toast if exceeded.
- Upload progress: replace Paperclip with circular progress ring (CSS, blue stroke)
- Uploaded file preview in chat: filename + file icon + size (Geist Mono 12px) + remove button (X)
- CSV/Excel triggers material list parsing: show parsed items as editable table in AI response

### 15. Editable Material List Table (inline in AI messages)
- Triggered by AI parsing or `/quote` command
- Table: border 1px `var(--color-border)`, rounded-xl, overflow hidden
- Header row: bg `var(--color-card)`, 12px 600 `var(--color-text-muted)`, h-36px
- Columns: Item Name | Qty | Unit
- Body rows: h-40px, 14px 400, border-top 1px `var(--color-border)`
- Qty in Geist Mono
- Inline edit: click cell to edit, focus ring on active cell
- Add row button: "+ Add item" / "+ أضف عنصر", 12px 400 `var(--color-primary)`, h-36px, full-width, dashed border top
- Delete row: X icon at inline-end of each row, 16px, `var(--color-text-muted)`, hover `var(--color-error)`
- Below table: "Submit as Quote Request" button, blue solid, h-40px, rounded-xl, 14px 600 white text, full-width

### 16. Chat Input Upgrade (extends Phase 7 AIChatInput)
- Convert from `<input>` to `<textarea>` for multi-line
- Default: 1 line (h-56px). Auto-expand to max 6 lines before scroll.
- Shift+Enter for new line, Enter to send
- Left-to-right button order in input bar (LTR): Sparkles | textarea | Paperclip | Mic | Send
- Right-to-left button order in input bar (RTL): Send | Mic | Paperclip | textarea | Sparkles
- All buttons 44px touch target (Paperclip and Mic at 20px icon size within 44px tap area)

### 17. Rate Limit Warning
- At 25 messages/minute: show inline warning above input
- "You're sending messages quickly. Limit: 30/min." / "أنت ترسل رسائل بسرعة. الحد: ٣٠/دقيقة."
- 12px 400 `var(--color-warning)`, with AlertTriangle icon 14px
- At 30: disable send button for cooldown, show countdown timer (Geist Mono)

### 18. Scroll-to-Bottom Pill
- Appears when user scrolls up more than 200px from bottom
- Position: bottom-center of chat area, mb-8px above input
- Pill: h-32px, rounded-full, bg `var(--color-card)`, border 1px `var(--color-border)`, shadow-sm
- Content: ChevronDown icon 16px + "New messages" / "رسائل جديدة" 12px 400
- Click: smooth scroll to bottom
- Tween entrance: opacity 0->1, y 8->0, 200ms

## State Management

| Store | Shape | Persistence |
|-------|-------|-------------|
| `usePortalStore` (extend) | Add: `{ chatMessages: Message[], conversationId: string \| null, quickActionContext: 'home' \| 'product' \| 'order', isHistoryOpen: boolean, supplierMessages: Message[] }` | sessionStorage via Zustand persist |
| Chat messages | `Message { id, role: 'user' \| 'assistant', content: string, richContent?: RichContent[], timestamp: number }` | sessionStorage (survives refresh) |
| Conversation history | Server state via TanStack Query: `getConversationHistory()` | Cache, staleTime 5min |
| File uploads | Local state in chat component, R2 URLs stored in messages | None (ephemeral) |

RichContent union type:
```
type RichContent =
  | { type: 'product_card'; data: { id, name, image, specs, priceRange } }
  | { type: 'status_card'; data: { entityType, entityId, status, dates } }
  | { type: 'action'; data: { label, route, params } }
  | { type: 'material_list'; data: { items: { name, qty, unit }[] } }
  | { type: 'disclaimer'; data: { text } }
```

## Accessibility Contract

- All interactive elements: 44px minimum touch target
- Focus visible: 2px offset ring using `var(--color-primary)` at 50% opacity
- Chat input: `role="textbox"`, `aria-label` for screen readers, `aria-multiline="true"`
- Send button: `aria-label="Send message"` / `aria-label="إرسال رسالة"`
- Stop button: `aria-label="Stop generating"` / `aria-label="إيقاف التوليد"`
- Voice button: `aria-label="Voice input"` / `aria-label="إدخال صوتي"`
- Attach button: `aria-label="Attach file"` / `aria-label="إرفاق ملف"`
- History button: `aria-label="Chat history"` / `aria-label="سجل المحادثات"`
- Slash command palette: `role="listbox"`, `aria-activedescendant` for keyboard nav
- Product card buttons: `aria-label="Add {product name} to quote"`
- Action buttons: descriptive labels matching button text
- History overlay: React Aria Dialog, focus trapped, Escape dismisses
- Screen reader: announce new AI messages via `aria-live="polite"` region
- Streaming: announce "AI is responding" when stream starts, "AI response complete" when done
- RTL: all logical properties (ps-/pe-/ms-/me-), `dir="rtl"` inherited from `<html>`
- Message alignment: use `text-align: start/end` and `margin-inline-start/end`, never `left/right`
