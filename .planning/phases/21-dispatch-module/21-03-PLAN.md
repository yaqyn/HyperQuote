       - MapLibre GL via `react-map-gl/maplibre` with `maplibre-gl/dist/maplibre-gl.css`
       - MapTiler style with VITE_MAPTILER_KEY fallback (same pattern as DeliveryMap)
       - Default viewport from dispatch store (Cairo)
       - Data-driven circle layer for vehicle pins (per RESEARCH.md code example):
         - `circle-color`: match on status property → yellow (#EAB308) loading, green (#22C55E) transit, blue (#2563EB) at_site, green (#16A34A) delivered, red (#EF4444) problem, grey (#9CA3AF) offline/default
         - `circle-radius`: interpolate by zoom (6 at zoom 8, 12 at zoom 14)
         - `circle-stroke-color`: white, stroke-width: 2
       - Cluster layer: larger circles with count text (Geist Mono) for clustered points
       - Click cluster → zoom in to expand
       - Click individual pin → show VehiclePopup
       - Route lines per driver:
         - Source per route with GeoJSON LineString
         - Completed portion: solid line, route color, opacity 1
         - Remaining portion: dashed line (`line-dasharray: [2, 2]`), same color, opacity 0.5
       - Geofence circles around delivery sites: 200m radius, semi-transparent fill
       - onMove: update mapViewport in store

    4. Create `VehiclePopup.tsx`:
       - Popup positioned at vehicle pin location
       - Content: Vehicle ID + driver name (bold), speed + heading (Geist Mono), status badge, current stop X of Y, next stop location + ETA (Geist Mono), contact buttons (`[Call Driver]` `[Message]`), `[View Route]` `[Details]`
       - Call/Message buttons: `tel:` link and custom event respectively
       - View Route: highlights that driver's route line on map
       - Details: sets selectedDriverId in store
       - Use React Aria Popover for accessible popup positioning
       - Close on click outside or Escape
