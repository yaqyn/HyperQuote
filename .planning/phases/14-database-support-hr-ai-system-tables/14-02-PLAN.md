**1. generate_sequence_number(p_tenant_id UUID, p_entity_type TEXT, p_prefix TEXT) RETURNS TEXT**

**2. calculate_payment_behavior_score(p_customer_id UUID) RETURNS DECIMAL(5,2)**
- Copy exact SQL from BACKEND.md Section 7.3
- STABLE SECURITY DEFINER

**3. calculate_customer_tier_score(p_customer_id UUID) RETURNS DECIMAL(5,2)**
- Copy exact SQL from BACKEND.md Section 7.4
- STABLE SECURITY DEFINER
- Composite: Order count (20%) + Spend (20%) + Payment (30%) + Tenure (15%) + Consistency (15%)

**4. calculate_available_quantity(p_product_id UUID, p_warehouse_id UUID DEFAULT NULL) RETURNS DECIMAL(12,3)**
- Copy exact SQL from BACKEND.md Section 7.5
- STABLE SECURITY DEFINER
- Returns on_hand - reserved - allocated - expired - damaged
- Supports per-warehouse or cross-warehouse

**5. calculate_ar_aging(p_customer_id UUID) RETURNS TABLE(...)**
- Copy exact SQL from BACKEND.md Section 7.6
- STABLE SECURITY DEFINER
- Returns current, 1-30, 31-60, 61-90, 90+ day buckets
- Filters invoices by status IN ('sent', 'viewed', 'partially_paid', 'overdue', 'collections', 'disputed')

**6. recalculate_wac(p_tenant_id, p_product_id, p_warehouse_id, p_new_quantity, p_new_unit_cost) RETURNS DECIMAL(12,4)**

- SECURITY DEFINER (not STABLE -- it does UPDATE)

**7. create_notification_group(p_tenant_id UUID, p_group_key TEXT, p_root_event_type TEXT, p_root_entity_id UUID, p_summary_text TEXT, p_summary_text_ar TEXT DEFAULT NULL, p_notifications JSONB DEFAULT '[]'::jsonb) RETURNS JSONB**

- INSERT into notification_groups with ON CONFLICT DO UPDATE (increment count)
- Loop over p_notifications JSONB array, INSERT each into notifications
- Return jsonb_build_object('group_id', v_group_id, 'notification_count', v_count)

All functions use `CREATE OR REPLACE FUNCTION` for idempotency.
