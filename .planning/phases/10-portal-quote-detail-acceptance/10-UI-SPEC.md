## Interaction Contracts

### Quote Timeline

- 7 steps: Submitted > Under Review > Sourcing > Quote Ready > Sent to You > Accepted/Negotiating > Order Confirmed
- Completed step: green check icon (Lucide `Check`, 16px, var(--color-success))
- Current step: blue pulsing ring (var(--color-primary), CSS animation `pulse` 2s infinite)
- Future step: gray circle (var(--color-text-subtle))
- Desktop: vertical layout, left-aligned
- Mobile: horizontal layout, scrollable

### Accept Flow

1. User taps "Accept Quote" (green bg, flex-1, 48px height)
2. AcceptConfirmModal opens (GlassElevated, isKeyboardDismissDisabled)
3. Modal shows: total in Geist Mono, payment terms, "This will create an order."
4. "Keep Reviewing" (outline) + "Accept Quote" (green bg)
5. On confirm: POST acceptQuote() > brief confetti animation (300ms) > view updates to order tracking > Toast "Order confirmed!"
6. Confetti: 20-30 particles, blue + white only, gravity fall, 300ms duration via Motion v12

### Counter-Offer Flow

1. User taps "Counter-Offer" (warning outline, 48px)
2. Two options presented: "Counter on total" / "Counter per line"
3. **Total mode:** Single NumberField (React Aria) with "%" suffix. Live recalculation of new total in Geist Mono.
4. **Per-line mode:** Click price cell > becomes NumberField input. Changed cells get amber bg (var(--color-warning-bg)). Old value shown as strikethrough muted text.
5. FloatingChangesBar appears at table bottom: "{N} items modified" + [Discard] (outline) + [Submit Counter-Offer] (blue bg, 48px)
6. Volume counter: NumberField for "I'll order {X} instead of {Y}" with live recalculation
7. Pickup checkbox: "I'll arrange my own pickup (reduce price)"
8. Notes: React Aria TextArea for Arabic free-text
9. Submit > confirmation modal > creates new quote version > status "Negotiating" > Toast "Counter-offer submitted."

### Partial Accept Flow

1. User taps "Partial Accept" (blue outline, 48px)
2. Per-line buttons appear: [Accept] [Reject] [Negotiate]
3. Accept: row gets green checkmark, line grays out (opacity 0.6)
4. Reject: strikethrough on product name + React Aria Select dropdown (reasons: Too expensive, Not needed, Found alternative, Other)
5. Negotiate: inline price edit (same as counter per-line, amber highlight)
6. PartialSummaryBar updates live: "8 accepted, 2 rejected, 4 pending"
7. [Submit Partial Response] enabled when all lines have a decision

### Decline Flow

1. User taps "Decline" (red outline, 48px)
2. DeclineModal opens (GlassElevated, isKeyboardDismissDisabled)
3. Optional reason: React Aria Select (Price too high, Found alternative, Project cancelled, Other)
4. Optional notes: TextArea
5. "Keep Quote" (outline) + "Decline" (red bg)
6. On confirm: status "Declined" > Toast "Quote declined."

### Payment Terms Box

- Background: var(--color-surface)
- Border radius: rounded-lg
- Padding: 16px (md token) -- overrides FRONTEND.md spec `p-12px` to maintain 8-point scale
- Typography: Inter 400 14px

### Version Comparison Modal

- GlassElevated, max-width 960px, max-height 80vh, centered
- Two-column layout: Version A (left) / Version B (right)
- Each column has React Aria Select for version picker
- Defaults: A = previous version, B = current version
- Diff rendering:
  - Changed cells: amber/yellow bg. Old value strikethrough Geist Mono 400 muted + new value Geist Mono 600
  - Added items: green-tinted bg (var(--color-success-bg)) + "NEW" badge
  - Removed items: red-tinted bg (var(--color-error-bg)) + strikethrough + "REMOVED" badge
- Summary bar at top: "Total changed from EGP 245,000 to EGP 231,500 (-5.5%)" -- Geist Mono for all numbers. Percentage green if decreased, red if increased.
- Mobile: stacked layout (A on top, B below), swipe hint text
- Close: X button. isKeyboardDismissDisabled (Escape via hotkeys)

### Validity Countdown

- > 3 days remaining: var(--color-text-muted), normal weight
- <= 3 days remaining: var(--color-warning), weight 600
- Expired: var(--color-error), weight 600, "Expired" label
- Format: "X days remaining" / "Expires today" / "Expired"
- All numbers in Geist Mono

## Motion Contract

| Interaction | Type | Duration | Easing |
|-------------|------|----------|--------|
| Quote detail window open | Spring | ~400ms | stiffness: 300, damping: 30 |
| Quote detail window close | Tween | 200ms | ease-out |

| Modal close | Tween | 150ms | ease-out |
| Confetti (accept) | Tween | 300ms | ease-out with gravity |
| Timeline step pulse | CSS animation | 2s infinite | ease-in-out |
| FloatingChangesBar appear | Tween | 150ms | ease-out, slide up from bottom |
| Line item highlight (amber) | Instant | 0ms | No animation (color changes are instant per UI-VISION) |
| Row gray-out (accepted line) | Tween | 150ms | ease-out |

## Accessibility Contract

- All modals use React Aria Dialog with `isKeyboardDismissDisabled`
- All Select dropdowns use React Aria Select with proper label associations
- All NumberField inputs use React Aria NumberField with formatOptions for currency
- Table uses React Aria Table with proper column headers and row semantics
- Status badge colors are NEVER the only indicator -- always paired with text labels
- Focus management: modal open traps focus, modal close returns focus to trigger
- Inline editing: Enter to confirm, Escape to cancel edit
- Currency amounts announced with unit: "56.40 Egyptian Pounds" not just "56.40"
