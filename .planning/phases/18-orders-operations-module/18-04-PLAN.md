**SLATracker.tsx** — React Aria Table per FRONTEND.md 3.4 SLA Tracker spec:

- Use `useQuery` to call `getSLAItems`.
- React Aria `Table` with `TableHeader`, `Column`, `TableBody`, `Row`, `Cell`.
- 5 columns:
  1. **Entity** — entityRef (Geist Mono 13px) + entityType badge below (Inter 400 11px muted).
  2. **SLA Type** — human label from `SLA_DURATIONS[item.slaType].label` (Inter 400 14px).
  3. **Deadline** — formatted date (Geist Mono 13px).
  4. **Time Remaining** — formatted as "Xh Ym" or "Overdue by Xh" (Geist Mono 13px). Color from `getTimeRemainingColor(item.remainingMs, item.totalMs)`.
  5. **Status** — badge using `computeSLAStatus`: "On Track" (bg-green-100 text-green-700), "At Risk" (bg-yellow-100 text-yellow-700), "Breached" (bg-red-100 text-red-700). Rounded-full px-2 py-0.5 text-xs font-medium.

- **Default sort:** breached first (remainingMs <= 0), then at-risk sorted by remainingMs ascending, then on-track. This is the data order from the server function.
- **User sort:** Allow sorting by clicking column headers (SLA Type, Deadline, Time Remaining, Status). Use React Aria `allowsSorting` on `Column`.
- **Filters above table:** Two React Aria `Select` dropdowns in a `flex gap-3 mb-4`:
  - SLA Type: "All Types" + 5 SLA type options.
  - Status: "All Statuses" + "On Track" / "At Risk" / "Breached".
  - Filter state is local `useState`, passed as params to `getSLAItems` query.
- **Section header:** "SLA Tracker" (Inter 600 16px) with filter bar on the right.
- **Container:** `rounded-xl border border-[var(--color-border)] bg-[var(--color-card)] p-4 mt-6`.
- **Empty state:** "No SLA items match your filters" centered text if filtered results are empty.

Format `remainingMs` to human-readable:
- If > 0: compute hours and minutes. "Xh Ym" format.
- If <= 0: "Overdue by Xh Ym" in red.
- Use Geist Mono for all time values.
