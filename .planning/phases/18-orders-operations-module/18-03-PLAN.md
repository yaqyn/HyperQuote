**OrderActions.tsx** — Action buttons at bottom of order detail:
- 4 buttons in a horizontal `flex gap-3` bar, `sticky bottom-0` with `bg-[var(--color-card)] border-t border-[var(--color-border)] p-4`:

  - `[Split Delivery]` — Scissors icon, outline. Opens confirmation dialog. On confirm calls `splitOrder` mutation.
  - `[Hold Order]` — PauseCircle icon, outline yellow. Opens dialog with reason TextArea. Calls `holdOrder` mutation.

- Each dialog uses React Aria `Dialog` + `Modal` + `ModalOverlay` with `isKeyboardDismissDisabled`.
- After successful mutation, invalidate `getOrderDetail` and `getOrderBoard` queries.

**CrossModuleHandoff.tsx** — Horizontal step indicator per FRONTEND.md 3.5:
- Expandable section at top of order detail. Default collapsed. Toggle button: "Handoff Status" (Inter 500 14px) + ChevronDown/Up icon.
- When expanded, show horizontal step indicator using `HANDOFF_STAGES` constant (6 stages: Sales, Procurement, Warehouse, Dispatch, Driver, Finance).
- Visual per stage:
  - Completed: green checkmark circle (Check icon, 16px, bg-green-500 text-white, rounded-full w-6 h-6) + label (Inter 400 13px).
  - Current: blue filled circle (bg-[#2563EB] text-white, rounded-full w-6 h-6) + bold label (Inter 600 13px).
  - Future: gray outline circle (border-2 border-black/20 dark:border-white/20, rounded-full w-6 h-6) + label (Inter 400 13px muted).
  - Connected by lines: `h-0.5 flex-1 bg-green-500` for completed, `bg-[#2563EB]` for current-to-next, `bg-black/10 dark:bg-white/10` for future.
- Below the pipeline: current owner name (Inter 500 14px) + time in current stage (Geist Mono 13px).
- If time in current stage exceeds SLA (`handoff.timeInStage > handoff.slaMs`), show amber/red warning banner: "Waiting on [Stage] for X hours (SLA: Y hours)" with red background.
- **Nudge button:** Lucide `Bell` icon (16px) + "Nudge" text. Outline button, height 32px. On click, calls `nudgeHandoff` mutation with `{ orderId, targetStage: handoff.currentStage }`. Show toast on success: "Notification sent to [name]".
- Use `useOperationsStore.selectedOrderId` and the `handoff` field from `getOrderDetail` query data.
