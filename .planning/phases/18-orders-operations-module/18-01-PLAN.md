**types/operations.ts** — Define all domain types (follow procurement.ts pattern):

Status unions:
- `FulfillmentStage = 'po_placed' | 'in_transit' | 'at_warehouse' | 'preparing' | 'out_for_delivery' | 'delivered'`
- `OrderStatus = 'confirmed' | 'processing' | 'partially_fulfilled' | 'fulfilled' | 'completed' | 'on_hold' | 'cancellation_requested' | 'back_ordered' | 'cancelled'`
- `SLAType = 'quote_response' | 'po_confirmation' | 'delivery_scheduling' | 'invoice_generation' | 'dispute_resolution'`
- `SLAStatus = 'on_track' | 'at_risk' | 'breached'`
- `HandoffStage = 'sales' | 'procurement' | 'warehouse' | 'dispatch' | 'driver' | 'finance'`
- `OperationsTab = 'dashboard' | 'kanban' | 'order-detail' | 'delivery-schedule'`
- `FulfillmentColor = 'green' | 'yellow' | 'red'`

Interfaces:
- `FulfillmentOrder` — id, orderNumber, customerName, totalValue (number), totalItems, readyItems, eta (string), color (FulfillmentColor), stage (FulfillmentStage), assignedTo (string)
- `OrderDetail` — id, orderNumber, customerName, quoteRef, totalValue, status (OrderStatus), createdAt, items (OrderLineItem[]), documents (OrderDocument[]), activityLog (ActivityLogEntry[]), handoff (HandoffStatus)
- `OrderLineItem` — id, productName, supplier, poNumber, quantity, fulfilledQuantity, status (string), eta (string)
- `OrderDocument` — id, type (string), name, url, createdAt
- `ActivityLogEntry` — id, action (string), actor (string), timestamp (string), details (string)
- `HandoffStatus` — currentStage (HandoffStage), currentOwner (string), timeInStage (number in ms), slaMs (number), completedStages (HandoffStage[])
- `SLAItem` — id, entityRef (string), entityType (string), slaType (SLAType), deadline (string), totalMs (number), remainingMs (number), status (SLAStatus)
- `BottleneckStage` — stage (string), label (string), count (number), avgDwellMinutes (number), stuckCount (number)
- `OperationsMetrics` — ordersInProgress (number), ordersInProgressTrend ('up' | 'down'), deliveriesToday (number), deliveriesTotal (number), slaBreaches (number), bottleneckStage (string), bottleneckStuckCount (number)
- `DeliveryScheduleItem` — id, orderId, orderNumber, customerName, items (string[]), method ('own_fleet' | '3pl' | 'drop_ship' | 'consolidated'), scheduledDate (string), status (string)
- `KanbanFilters` — customer (string | null), dateRange ([string, string] | null), deliveryMethod (string | null), status (FulfillmentStage | null)

Export helper functions:
- `computeSLAStatus(remainingMs: number, totalMs: number): SLAStatus` — returns 'breached' if remainingMs <= 0, 'at_risk' if ratio < 0.5, 'on_track' otherwise
- `getSLAStatusColor(status: SLAStatus): string` — 'green' / 'yellow' / 'red'
- `getTimeRemainingColor(remainingMs: number, totalMs: number): string` — 'text-red-600' / 'text-yellow-600' / 'text-green-600' based on ratio thresholds (0, 0.25, 0.5)
- `getFulfillmentColor(color: FulfillmentColor): string` — returns Tailwind border class 'border-s-green-500' / 'border-s-yellow-500' / 'border-s-red-500'
- `FULFILLMENT_COLUMNS: { stage: FulfillmentStage; label: string }[]` — the 6 columns with labels: 'PO Placed', 'In Transit from Supplier', 'At Warehouse', 'Preparing / Loading', 'Out for Delivery', 'Delivered'
- `HANDOFF_STAGES: { stage: HandoffStage; label: string }[]` — 6 handoff stages with labels
- `SLA_DURATIONS: Record<SLAType, { label: string; durationMs: number }>` — 4h, 24h, 48h, 24h, 72h in milliseconds
