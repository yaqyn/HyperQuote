**powersync.ts:** Add 5 new tables to the DriverSchema following the existing `new Table({...})` pattern:

1. `delivery_exceptions` table:
   - `delivery_id: column.text`, `stop_id: column.text`, `type: column.text` (ExceptionType enum value), `photos: column.text` (JSON array of URIs), `gps_lat: column.real`, `gps_lng: column.real`, `details: column.text` (JSON object), `resolution: column.text` ('wait'|'skip'|'failed'|'reroute'), `dispatch_notified: column.text`, `created_at: column.text`

2. `driver_jobs` table:
   - `delivery_id: column.text`, `status: column.text` ('available'|'offered'|'accepted'|'declined'|'expired'|'completed'|'cancelled'), `offered_at: column.text`, `expires_at: column.text`, `accepted_at: column.text`, `completed_at: column.text`, `payout_amount: column.real`, `payout_currency: column.text`, `pickup_address: column.text`, `delivery_address: column.text`, `estimated_distance_km: column.real`, `estimated_duration_minutes: column.integer`, `materials_summary: column.text`, `total_weight_kg: column.real`, `requires_moffett: column.text`, `requires_boom: column.text`

3. `driver_earnings` table:
   - `driver_id: column.text`, `period_start: column.text`, `period_end: column.text`, `total_jobs: column.integer`, `total_earned: column.real`, `withholding_tax: column.real`, `net_payable: column.real`, `status: column.text`, `paid_at: column.text`

4. `driver_withdrawals` table:
   - `driver_id: column.text`, `amount: column.real`, `bank_account_id: column.text`, `status: column.text` ('pending'|'processing'|'completed'|'failed'), `requested_at: column.text`, `completed_at: column.text`

5. `shift_returns` table:
   - `shift_id: column.text`, `delivery_id: column.text`, `delivery_item_id: column.text`, `product_name: column.text`, `quantity: column.real`, `unit: column.text`, `reason: column.text` ('damaged'|'customer_refused'|'not_needed'|'other'), `linked_exception_id: column.text`, `notes: column.text`, `created_at: column.text`

**stores/exception.ts:** Create exception reporting Zustand store following the RESEARCH.md Pattern 1 exactly. Export `useExceptionStore`. The store must have:
- State: `type: ExceptionType | null`, `deliveryId: string | null`, `stopId: string | null`, `photos: string[]`, `gpsLat: number | null`, `gpsLng: number | null`, `details: Record<string, unknown>`, `step: number`
- ExceptionType union: `'customer_unavailable' | 'site_blocked' | 'wrong_address' | 'damaged_goods' | 'partial_delivery' | 'weather_delay' | 'vehicle_issue'`
- Actions: `setType(type)` (sets step to 1), `setDelivery(deliveryId, stopId)`, `addPhoto(uri)`, `removePhoto(index)`, `setDetails(key, value)`, `setGps(lat, lng)`, `nextStep()`, `prevStep()`, `submit()` (inserts into `delivery_exceptions` table + updates `deliveries.failure_reason` + queues photos in `upload_queue`), `reset()`
- The `submit()` action must use the failure reason mapping: customer_unavailable->customer_absent, site_blocked->access_blocked, wrong_address->wrong_address, damaged_goods->damaged_in_transit, partial_delivery->customer_refused, weather_delay->weather, vehicle_issue->vehicle_breakdown
- Export the `ExceptionType` type and `EXCEPTION_TYPES` constant array (7 items with `type`, `labelKey`, `requiresPhoto` fields)

**stores/end-of-day.ts:** Create end-of-day Zustand store following RESEARCH.md Pattern 2. Export `useEODStore`. The store must have:
- EODStep type: `'returns' | 'fuel' | 'post-trip-dvir' | 'odometer' | 'summary' | 'sign-off'`
- `getStepsForDriverType(driverType: string): EODStep[]` -- internal gets all 6 steps, contracted/on_demand skip 'returns' and 'post-trip-dvir' (4 steps: fuel, odometer, summary, sign-off)
- State: `currentStep: EODStep`, `steps: EODStep[]`, `returns: ReturnItem[]`, `fuelLevel: '1/4' | '1/2' | '3/4' | 'full' | null`, `fuelReceiptPhotoUri: string | null`, `endOdometer: number | null`, `odometerPhotoUri: string | null`, `postTripInspectionId: string | null`, `signatureDataUrl: string | null`, `shiftSummary: ShiftSummary | null`
- ReturnItem interface: `{ deliveryId: string, itemId: string, productName: string, quantity: number, unit: string, reason: 'damaged' | 'customer_refused' | 'not_needed' | 'other', notes: string }`
- ShiftSummary interface: `{ stopsCompleted: number, stopsFailed: number, totalKm: number, totalDriveTime: number, onTimePercent: number, exceptionsLogged: number, returnsCount: number }`
- Actions: `init(driverType: string)` (sets steps and currentStep), `nextStep()`, `prevStep()`, `addReturn(item)`, `removeReturn(index)`, `setFuelLevel(level)`, `setFuelReceiptPhoto(uri)`, `setEndOdometer(reading)`, `setOdometerPhoto(uri)`, `setPostTripInspectionId(id)`, `setSignature(dataUrl)`, `loadSummary(shiftId: string)` (reads from PowerSync), `endShift()` (coordinates: insert post-trip inspection if internal, update driver_shifts, update routes, insert shift_returns, attempt processUploadQueue), `reset()`
- `isFuelLow` computed: true if fuelLevel is '1/4' (warning, not blocking)
- `canEndShift` computed: true if fuelLevel set, endOdometer set, signatureDataUrl set

**stores/external-driver.ts:** Create external driver Zustand store. Export `useExternalDriverStore`. The store must have:
- State: `jobs: DriverJob[]`, `selectedJob: DriverJob | null`, `earnings: EarningsSummary`, `earningsHistory: EarningsHistoryItem[]`, `withdrawals: Withdrawal[]`
- DriverJob interface: `{ id: string, deliveryId: string, status: string, offeredAt: string, expiresAt: string, payoutAmount: number, payoutCurrency: string, pickupAddress: string, deliveryAddress: string, estimatedDistanceKm: number, estimatedDurationMinutes: number, materialsSummary: string, totalWeightKg: number, requiresMoffett: boolean, requiresBoom: boolean }`
- EarningsSummary: `{ thisWeek: number, thisMonth: number, pending: number, available: number, rating: number, totalJobs: number }`
- EarningsHistoryItem: `{ id: string, jobId: string, date: string, amount: number, status: 'pending' | 'approved' | 'paid' | 'processing', breakdown: { basePay: number, distanceBonus: number, heavyLoadSurcharge: number, nightPremium: number } }`
- Withdrawal: `{ id: string, amount: number, status: string, requestedAt: string, completedAt: string | null }`
- Actions: `loadJobs()` (reads from driver_jobs where status in available/offered), `loadJob(jobId)`, `acceptJob(jobId)` (updates status to 'accepted', sets accepted_at), `declineJob(jobId, reason?)` (updates status to 'declined'), `loadEarnings(driverId)`, `loadEarningsHistory(driverId)`, `requestWithdrawal(amount, bankAccountId)` (validates minimum EGP 500, inserts into driver_withdrawals), `reset()`
- Withholding calculation helper exported: `calcWithholding(amount: number): { gross: number, withholding: number, net: number }` -- uses `Math.round(amount * 5) / 100` for 5% Egyptian services tax
- MINIMUM_WITHDRAWAL constant exported: `500`
