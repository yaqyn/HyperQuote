**PhotoGrid.tsx:** Shared component for exception photo capture/display. Props: `photos: string[]`, `onAdd: () => void`, `onRemove: (index: number) => void`, `minRequired?: number`, `maxPhotos?: number`. Renders a grid of photo thumbnails (rounded-lg, 80x80) with an "Add Photo" button (56dp min, dashed border). Shows `{current}/{min} required` count in Geist Mono when minRequired is set. Uses DriverButton for the add action.

**ExceptionWizard.tsx:** Coordinator component. Reads `useExceptionStore` state. Based on `step`:
- step 0: Type selection grid. Render `EXCEPTION_TYPES` as a 2-column grid of DriverCard buttons (56dp min height each). Each card shows icon placeholder + translated label from `t(item.labelKey)`. `onPress` calls `store.setType(item.type)`.
- step 1+: Renders the type-specific component based on `store.type`:
  - `customer_unavailable` -> `<CustomerUnavailable />`
  - `site_blocked` -> `<SiteBlocked />`
  - `wrong_address` -> `<WrongAddress />`
  - `damaged_goods` -> `<DamagedGoods />`
  - `partial_delivery` -> `<PartialDelivery />`
  - `weather_delay` -> `<WeatherDelay />`
  - `vehicle_issue` -> `<VehicleIssue />`
- Back button calls `store.prevStep()` or `store.reset()` if at step 0.
- All components share the same ExceptionWizard wrapper layout: title bar with back arrow, scrollable content, fixed bottom actions.

**CustomerUnavailable.tsx:** Guided workflow with steps:
1. "Did you call the site contact?" -- Yes/No radio (React Aria RadioGroup). Auto-filled hint: "Contact: {stop.contact_phone}" from delivery context.
2. "Did you try an alternate contact?" -- Yes/No radio.
3. "Response received?" -- Yes/No radio.
4. 15-minute mandatory wait timer. **CRITICAL:** Store `waitStartedAt` as ISO timestamp in store details (not setInterval). Display computed remaining time using `useEffect` with 1-second interval that calculates diff from stored timestamp. This survives app backgrounding. Show countdown in Geist Mono (`font-[var(--font-mono)]`), large (text-3xl). Below timer: "Impact on remaining stops: calculating..." text.
5. Actions: [Wait] (DriverButton secondary), [Skip and Return Later] (secondary), [Mark Failed -- Return to Warehouse] (danger). Each calls `store.setDetails('resolution', 'wait'|'skip'|'failed')` then `store.nextStep()` to go to summary.

**SiteBlocked.tsx:** 
1. Photo of obstruction (required) -- PhotoGrid with minRequired=1.
2. Type of blockage: RadioGroup with options: 'gate_locked', 'construction_barrier', 'road_closure', 'flooding', 'other'. Store in `details.blockageType`.
3. "Called site contact?" -- Yes/No radio.
4. Actions: [Wait] [Skip] [Mark Failed] -- same pattern as CustomerUnavailable.

**WrongAddress.tsx:**
1. Photo of location (required) -- PhotoGrid minRequired=1.
2. "What is at this location?" -- React Aria TextField (multiline). Store in `details.locationDescription`.
3. "Called customer for correct address?" -- Yes/No.
4. If yes + new address: React Aria TextField for new address. Store in `details.newAddress`. Show text: "Route recalculation would happen here."
5. Actions: [Navigate to New Address] (primary, only if newAddress set), [Skip -- Too Far] (secondary).

**All components:** Use React Aria components (RadioGroup, Radio, TextField). Use `useTranslation('driver')` for all user-facing strings with `exception.` namespace prefix. Use `DriverCard` for sections, `DriverButton` for actions. All touch targets 56dp minimum. All numbers in `font-[var(--font-mono)]`.

1. "When discovered?" -- RadioGroup: 'at_loading', 'in_transit', 'at_delivery'. Store in `details.discoveredAt`.
2. Affected items -- Load delivery items from `useDeliveryStore` or from PowerSync query on `delivery_items WHERE delivery_id = ?`. Show checkable list (React Aria CheckboxGroup) of items with product_name + quantity + unit.
3. Per selected item: Damage type RadioGroup ('bent_deformed', 'broken', 'wet', 'crushed', 'rusted', 'other'), Severity RadioGroup ('minor', 'moderate', 'severe'), Quantity affected NumberField. Store in `details.damagedItems` as array.
4. Photos -- PhotoGrid minRequired=2, maxPhotos=6. Text: "Minimum 2 photos, recommended 4-6".
5. "Who noticed?" -- RadioGroup: 'driver', 'customer', 'warehouse'.
6. "Customer decision:" -- RadioGroup: 'accepts_undamaged', 'refuses_entire', 'accepts_with_notation'.
7. Action: [Submit Damage Report] (danger) -- auto-notifies dispatch + claims team (via store submit).

**PartialDelivery.tsx:**
1. "Customer says:" -- TextField multiline. Store in `details.customerStatement`.
2. Items customer WANTS now -- CheckboxGroup of delivery items. Selected items = delivered, unselected = returned.
3. "Contacted dispatch?" -- DriverButton "Call Dispatch" (primary, 56dp). Store `details.dispatchContacted: true` on press.
4. "Dispatch approved?" -- RadioGroup: 'yes', 'waiting'.
5. Action: [Confirm Partial] -- sets resolution to 'partial', undelivered items get reason code "customer_request_not_ready".

**WeatherDelay.tsx:**
1. Condition -- RadioGroup: 'heavy_rain', 'sandstorm_khamsin', 'extreme_heat', 'high_wind'.
2. Impact -- RadioGroup: 'cannot_drive', 'cannot_unload', 'materials_at_risk'.
3. Photo of conditions -- PhotoGrid minRequired=1.
4. Khamsin-specific warning: If condition is 'sandstorm_khamsin' or 'high_wind', show prominent yellow banner: "Block deliveries of sheet materials above 30 km/h wind." (per CONTEXT.md spec).
5. Actions: [Wait for Conditions to Clear] [Skip Delivery] [Mark Failed].

**VehicleIssue.tsx:**
1. Issue type -- RadioGroup: 'engine_failure', 'flat_tire', 'hydraulic_failure', 'electrical_issue', 'overheating', 'other'.

6. If severity is 'cannot_continue': Show additional emergency section with [Emergency: 123 (Ambulance)] and [Emergency: 122 (Traffic Police)] buttons, each 56dp, red bg.
