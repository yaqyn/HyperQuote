**CountdownTimer.tsx:** Real-time countdown component following RESEARCH.md Pattern 3 exactly.
- Props: `expiresAt: string` (ISO timestamp), `onExpired?: () => void`.
- Uses `useState` + `useEffect` with `setInterval(update, 1000)`.
- Computes remaining from `new Date(expiresAt).getTime() - Date.now()`.
- Displays `MM:SS` format in `font-[var(--font-mono)] text-2xl font-medium`.
- When remaining <= 0: displays "00:00", calls `onExpired()` once, clears interval.
- When remaining < 5 minutes: add `text-[var(--color-danger)]` for urgency.
- Cleanup: `return () => clearInterval(interval)` in useEffect.

**JobCard.tsx:** Job offer card for the listing.
- Props: `job: DriverJob`, `onPress: () => void`.
- Wrapped in DriverCard. Layout:
  - Top row: Payout amount (Geist Mono, text-xl, bold, blue) + CountdownTimer aligned right.
  - Pickup → Delivery: Two-line address display with arrow icon between.
  - Details row: Distance (km, Geist Mono), Duration (min, Geist Mono), Weight (kg, Geist Mono).
  - Materials summary: single line, truncated.
  - Equipment tags: If `requiresMoffett` or `requiresBoom`, show small badge.
  - Bottom: DriverButton "View Details" (secondary) calling `onPress`.
- Entire card is tappable (56dp min height).
- All numbers in `font-[var(--font-mono)]`.
- Payout displayed as `EGP {amount}` with Arabic-Indic numerals support via `Intl.NumberFormat`.
