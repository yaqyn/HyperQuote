**ReturnsList.tsx:** (Internal drivers only — skipped for external)
- Load undelivered/returned items from today's deliveries via PowerSync: `SELECT di.*, d.order_id FROM delivery_items di JOIN deliveries d ON di.delivery_id = d.id WHERE d.driver_id = ? AND di.status IN ('refused', 'damaged') AND d.scheduled_date = ?`
- Display each returned item in a DriverCard: product_name, quantity (Geist Mono), unit.
- For each item: reason code Select (React Aria Select with options: 'damaged', 'customer_refused', 'not_needed', 'other'), notes TextField, link to existing damage report if any.
- "Add Manual Return" button for items not captured during delivery.
- Each completed return calls `store.addReturn(item)`.
- Bottom: "Warehouse receiving confirmation" checkbox (React Aria Checkbox) — informational, stored in details.
- [Continue] DriverButton primary to advance to next step.

**FuelReport.tsx:**
- Fuel gauge selector: 4 large buttons in a row (1/4, 1/2, 3/4, Full), 56dp each, showing visual fuel gauge icon/level. Selected state: blue bg. Unselected: white with border.
- If selected level is '1/4': Show prominent yellow warning banner: "Fill up before ending shift. Minimum 1/2 tank required at end of shift." — WARNING only, NOT blocking. The [Continue] button remains enabled.
- Optional fuel receipt photo: DriverButton secondary "Add Fuel Receipt Photo" → calls `capturePhoto()` → `store.setFuelReceiptPhoto(uri)`. Show thumbnail if captured.
- All fuel level labels in Geist Mono.
- [Continue] DriverButton primary (always enabled once a level is selected).

**PostTripDVIR.tsx:** (Internal drivers only — skipped for external)
- Reuse the existing `DVIRChecklist` and `InspectionItem` components from `components/inspection/`.
- At the TOP: Show open defects from pre-trip inspection. Query PowerSync: `SELECT * FROM vehicle_inspection_items WHERE inspection_id = ? AND status = 'fail'` using the shift's `inspection_id` from `useShiftStore`. Display these as read-only DriverCards with "Pre-trip defect" label.
- Below: Full 10-item post-trip checklist using `DVIRChecklist` component (or recreating its pattern with `DVIR_ITEMS` from shift store).
- NEW defects found during the day require: photo (required), severity selection. Use `capturePhoto()` for photos.
- Digital signature at bottom using `SignOff` component (or `react-signature-canvas` directly).
- On complete: Insert post-trip inspection into PowerSync `vehicle_inspections` table with `inspection_type: 'post_trip'`, insert items into `vehicle_inspection_items`. Call `store.setPostTripInspectionId(id)`.
- [Continue] DriverButton primary.

**EndOdometer.tsx:**
- Large numeric input for end-of-shift odometer reading. Use React Aria NumberField with large font (text-4xl, Geist Mono). Min value: start odometer from shift store + 1.
- Photo of odometer reading: DriverButton "Take Photo" → `capturePhoto()` → `store.setOdometerPhoto(uri)`. Show thumbnail.
- Display start odometer (Geist Mono) for reference: "Start: {value}".
- Display computed distance: `endOdometer - startOdometer` km in Geist Mono.
- [Continue] DriverButton primary (enabled when odometer value set).

**DaySummary.tsx:**
- Calls `store.loadSummary(shiftId)` on mount to compute stats from PowerSync data.
- Displays stats in a grid of DriverCards, ALL values in `font-[var(--font-mono)] font-medium` (Geist Mono 500):
  - Stops completed / failed (e.g., "8 / 2")
  - Total km driven
  - Total drive time (hours:minutes)
  - On-time delivery % 
  - Exceptions logged
  - Returns count
- Read-only summary — no inputs, just display.
- [Continue] DriverButton primary to proceed to sign-off.

**ShiftSignOff.tsx:**
- Signature capture using `react-signature-canvas` (same pattern as pre-trip SignOff component). Store result via `store.setSignature(dataUrl)`.
- Below signature: "I confirm this end-of-shift report is accurate" text.
- **[End Shift]** button: DriverButton variant="danger", 56dp height, full-width. Text: "End Shift".
- On press: Show confirmation overlay/modal: "Are you sure? This will end your shift and stop GPS tracking." with [Cancel] (secondary) and [End Shift] (danger) buttons.
- On confirm: call `store.endShift()`. Show loading state during execution.
- On success: navigate to a completion screen or back to `/login` (shift is over).
- External driver variation: Instead of "End Shift", show "Job Complete. Earnings: EGP {amount}" in Geist Mono before the sign-off button. Read earnings from the completed job if available.
