    - All prices in Geist Mono.

    - Chronological list of negotiation events:
      - Quote sent events (timestamp + method)

      - Internal notes (flagged "Internal Only" -- not visible to customer)
      - System events (e.g., "Quote viewed 3 times", "Quote expiring in 2 days")
    - Each event: icon + description + timestamp. Internal notes have a lock icon.
