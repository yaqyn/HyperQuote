| Property | Value |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, category badge margin-bottom |
| md | 16px | Grid gap, card padding, section padding |
| lg | 24px | Card internal spacing, filter group gaps |
| xl | 32px | Layout gaps between sidebar and grid |
| 2xl | 48px | Page-level vertical padding (market page top/bottom) |
| 3xl | 64px | Mobile bottom bar height on product detail |

Exceptions: 44px minimum touch target for mobile filter buttons and "Add to Quote" CTA. 80px sticky top offset for sidebar and product detail sticky card (header 64px + 16px gap). 256px filter sidebar width. 48px search field height. 48px CTA button height.

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | var(--color-base) #FFFFFF | Page background, card backgrounds |
| Secondary (30%) | var(--color-surface) #F8FAFC / var(--color-card) | Filter sidebar bg, product cards, specs table alternating rows, search field bg |
| Accent (10%) | var(--color-primary) #2563EB | "Add to Quote" button fill, pagination active page, category badge on product detail, price range text on cards, "Clear All" link, sort dropdown focus ring |
| Destructive | var(--color-error) #DC2626 | Not used in this phase |

Accent reserved for:
- "Add to Quote" button (solid blue background, white text)
- "Add to Quote" outline button on card hover (blue border, blue text)
- Pagination active page indicator (blue bg, white text, rounded-lg 32px square)
- "Clear All" / "Clear Filters" interactive link
- Focus rings on all React Aria components
- Price range text color on product cards (Geist Mono)

Availability indicator dots:
- Green (var(--color-success) #16A34A): "Available" / "In Stock"
- Yellow (var(--color-warning) #CA8A04): "Low Stock"
- Muted (var(--color-text-muted) #64748B): "Out of Stock" / "Price on Request"

> **Three-color rule exception:** Semantic status tokens (success/warning) are system-level indicators, not brand palette colors. Exception documented per CLAUDE.md three-color rule.

## Interaction States

### Market Page

| State | Visual Treatment |
|-------|-----------------|
| Loading (initial) | 6 skeleton cards (grid) or 8 skeleton rows (list). Skeleton shimmer animation. |
| Loading (filter/page change) | Existing content dims to 50% opacity. New skeletons replace after 200ms delay. |
| Empty (no results) | Lucide SearchX icon (48px, var(--color-text-muted)) + heading + body + "Clear Filters" button. Centered in grid area. |
| Error (fetch failed) | Lucide AlertTriangle icon (48px, var(--color-warning)) + heading + body + "Retry" button. Centered in grid area. |
| Card hover (desktop) | translateY(-2px) transition 150ms ease-out. shadow-md. "Add to Quote" outline button fades in at card bottom. |
| Card hover (mobile) | No hover. "Add to Quote" outline button always visible. |
| Filter active | "Clear All" link appears at top of sidebar. Active checkbox/radio has blue fill. URL updates. |
| Search active | Results update after 300ms debounce. Clear button appears in search field. |
| Pagination active | Current page: blue bg, white text, 32px square, rounded-lg. Other pages: transparent bg, var(--color-text). |

### Product Detail Page

| State | Visual Treatment |
|-------|-----------------|
| Loading | Skeleton: image placeholder (1:1 square), text lines for name/category/price, table rows for specs. |
| 404 | Lucide PackageX icon (48px, var(--color-text-muted)) + heading + body + "Browse Market" link. Centered. |
| Image hover (desktop) | Scale 1.5x within overflow-hidden container. Transition 300ms ease-out. |
| Image tap (mobile) | Opens full-screen viewer overlay (black bg, pinch-to-zoom). |
| Sticky card | Becomes position: sticky at top 80px when scrolling past its natural position. |
| Mobile bottom bar | Fixed at bottom, appears when card scrolls out of viewport. z-index above content. |
| "Add to Quote" (logged in) | Adds to draft quote. Success toast: "Added to quote". |
| "Add to Quote" (not logged in) | Opens Login Modal (Phase 6 dependency — stub as console.log for now). |

## RTL Considerations

| Element | RTL Behavior |
|---------|-------------|
| Filter sidebar | Appears at inline-end (right side in LTR, left in RTL). Use logical properties only. |
| Product grid | Reads right-to-left naturally with CSS Grid. |
| Breadcrumbs | ChevronRight separator flips to ChevronLeft in RTL. |
| Search field | Search icon at inline-start. Clear button at inline-end. |
| Price format | "من ٤٥ ج.م/كيس" — Arabic-Indic numerals, Arabic unit names. |
| Specs table | Property column always at inline-start. No swap. Labels translated. |
| Pagination | Number order preserved (1, 2, 3... reads LTR even in RTL context for numerals). |
| Mobile bottom bar | Quantity input at inline-start, button at inline-end. |

## URL State Contract

All filter/sort/pagination state lives in URL search params via TanStack Router with Zod validateSearch.

| Param | Type | Default | Example |
|-------|------|---------|---------|
| q | string? | undefined | ?q=cement |
| category | string[]? | undefined | ?category=cement,steel |
| availability | enum? | undefined | ?availability=available |
| price_tier | string[]? | undefined | ?price_tier=budget,premium |
| sort | enum? | "relevance" | ?sort=name |
| view | enum? | localStorage or "grid" | ?view=list |
| page | number? | 1 | ?page=2 |
