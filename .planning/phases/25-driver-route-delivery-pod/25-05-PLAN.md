  <action>
    1. Create components/pod/PODPhotos.tsx:
       - Grid of photo slots: minimum 1 required, up to 6.
       - Each slot: thumbnail preview after capture, or [+] button to add photo.
       - Uses capturePhoto() from lib/camera.ts (already handles 1920px max, JPEG 0.7 compression).
       - Auto-tag each photo with GPS (getCurrentPosition from geofence.ts) + timestamp.
       - Store metadata: { uri, lat, lng, accuracy, timestamp }.
       - [Remove] button on captured photos (with confirm).
       - Display count: "2/6 photos" in Geist Mono.
       - Required indicator on first slot: "At least 1 photo required".

    2. Create components/pod/SignaturePad.tsx:
       - Full-screen (or near full-screen) signature canvas using react-signature-canvas.
       - Large canvas height (minimum 200px, ideally 40vh) for finger input per spec.
       - Pen color: black (#0F172A). Stroke width: 3px for finger thickness.
       - [Clear] button to reset canvas.
       - "Print name" text field (React Aria TextField, required).
       - "Title/role" dropdown (React Aria Select): Foreman, PM, Site Engineer, Owner, Superintendent, Other.
       - If "Other": text input for custom role.
       - Export signature to data URL on parent request (via ref/callback).
       - RTL support: canvas is direction-agnostic (handwriting works in any direction).

    3. Create components/pod/ConditionSelect.tsx:
       - React Aria RadioGroup with two options: "Good condition" / "Damage noted".
       - 56dp touch targets per option.
       - If "Damage noted" selected: optional text area for condition notes.
       - Green highlight on "Good condition", yellow/amber on "Damage noted".

    4. Create components/pod/SwipeToComplete.tsx:
       - Full-screen-width swipe gesture track. Pill-shaped with rounded ends.
       - Thumb (circle with arrow icon) follows finger along track.
       - Track changes color as thumb progresses (gray -> blue gradient).
       - Must swipe minimum 80% of track width to trigger completion.
       - If finger released before 80%: spring back to start (Motion v12 spring).
       - At 80%+: snap to end, haptic feedback (Haptics.impact Heavy), trigger onComplete callback.
       - Haptic at 50% threshold (Haptics.impact Medium) as progress feedback.
       - Disabled state: grayed out, no interaction.
       - RTL: swipe direction flips (start from end-side, swipe toward start-side).
       - Text on track: "Swipe to confirm delivery" (i18n).
       - Implementation: track touch/pointer events on the container. Use motion/react animate for thumb position and spring-back. Calculate deltaX as percentage of container width.
