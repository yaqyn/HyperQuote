  <action>
    1. Create components/delivery/UnloadingTimer.tsx:
       - Displays elapsed unloading time in HH:MM:SS format, Geist Mono, 24sp.
       - Uses useDeliveryStore.unloadingDuration (updated by interval in store).
       - Auto-starts when first item is confirmed (via startUnloadingTimer in parent).
       - Stops when all items resolved.
       - Subtle pulse animation while running (opacity toggle via Motion v12).

    2. Create components/delivery/QuantityAdjust.tsx:
       - Modal/overlay for partial delivery quantity adjustment.
       - React Aria NumberField (Geist Mono, large) with min 0, max = quantity_expected.
       - Reason code required: React Aria RadioGroup with 4 options:
         'damaged_at_warehouse' | 'not_loaded' | 'customer_request' | 'other'.
       - If 'other': text input for custom reason.
       - [Confirm] button calls deliveryStore.adjustQuantity(itemId, quantity, reason).
       - [Cancel] button closes without changes.

    3. Create components/delivery/DamageReport.tsx:
       - Modal/overlay triggered by "Flag damage" action on an item.
       - Damage notes text area (React Aria TextArea).
       - Photo capture button (uses capturePhoto from lib/camera.ts). Shows thumbnail after capture.
       - [Submit] calls deliveryStore.flagDamage(itemId, notes, photoUri).
       - [Cancel] closes.

    4. Create components/delivery/LineItemList.tsx:
       - Renders delivery_items from useDeliveryStore.items.
       - Each item row (56dp min height):
         - Product name (font-semibold), quantity expected (Geist Mono), unit.
         - Status icon: pending (gray circle), delivered (green check), partial (yellow half), damaged (red X), refused (gray X).
         - Tap row to confirm full quantity: calls deliveryStore.confirmItem(itemId). Green checkmark animation.
         - "Adjust quantity" button -> opens QuantityAdjust overlay for that item.
         - "Flag damage" button -> opens DamageReport overlay for that item.
       - On FIRST item confirmation: trigger deliveryStore.startUnloadingTimer().
       - Bottom summary: confirmed/total items (Geist Mono), any partial/damaged counts.
  </action>
