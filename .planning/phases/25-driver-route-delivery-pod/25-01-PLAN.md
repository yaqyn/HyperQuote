    2. Extend powersync.ts -- add two new tables to DriverSchema:
       - `load_verifications`: route_id (text), vehicle_id (text), verified_by (text), scan_results (text/JSON), total_items_expected (integer), total_items_scanned (integer), weight_expected_kg (real), weight_actual_kg (real), weight_variance_percent (real), truck_photo_uri (text), cargo_photo_uri (text), driver_signature_url (text), gate_clearance (text: approved|blocked|override), created_at (text)
       - `proof_of_delivery`: delivery_id (text), signer_name (text), signer_role (text), signature_url (text), photos (text/JSON array of URIs), gps_lat (real), gps_lng (real), gps_accuracy_meters (real), condition_notes (text), condition_status (text: good|damaged), offline_captured (text), captured_at (text), created_at (text)
       - Also add columns to route_stops: contact_phone (text), delivery_window_start (text), delivery_window_end (text), ppe_required (text), access_instructions (text), previous_delivery_notes (text), site_photos (text)

    3. Create lib/map.ts (per RESEARCH.md Pattern 1):
       - `initMapProtocol()`: Register PMTiles protocol with MapLibre. Idempotent.
       - `createMap(container, options?)`: Create MapLibre map with PMTiles source, Cairo default center [31.2357, 30.0444], zoom 11, no attribution. Return Map instance.
       - `cleanupMap(map)`: Proper cleanup via map.remove().
       - MapLibre v5 pattern: use subscription.unsubscribe() for event cleanup, NOT map.off().

    4. Create lib/geofence.ts (per RESEARCH.md Pattern 2):
       - `initBackgroundGeolocation()`: Configure with DESIRED_ACCURACY_HIGH, distanceFilter 10m, stopOnTerminate false.
       - `addStopGeofences(stops[])`: Create geofences at each stop (default 200m radius). Use DWELL event (loiteringDelay 120000ms = 2 min) for auto-arrival to avoid GPS jitter re-triggers (Pitfall 4).
       - `onGeofenceEvent(callback)`: Subscribe to geofence ENTER/EXIT/DWELL events.
       - `startTracking()` / `stopTracking()`: Start/stop background GPS.
       - `getCurrentPosition()`: Get current lat/lng.

    5. Create lib/barcode.ts (per RESEARCH.md Pattern 3):
       - `checkScanPermission()`: Check/request camera permission for scanning.
       - `scanBarcode()`: Open ML Kit scanner overlay, scan QR/Code128/Code39/EAN13/EAN8. Return rawValue or null.

    6. Create lib/navigation.ts (per RESEARCH.md Pattern 4):
       - `getAvailableNavApp()`: Check Sygic first (`com.sygic.aura://`), then HERE (`here-route://`). Return 'sygic' | 'here' | null.
       - `launchNavigation(lat, lng, label?)`: Launch Sygic with `com.sygic.aura://coordinate|lng|lat|drive` or HERE with `https://share.here.com/r/lat,lng,name`. Return boolean (true = launched, false = neither installed).
       - NOT Google Maps -- spec forbids it (no truck profiles).

    7. Create lib/truck-ban.ts (per RESEARCH.md Pattern 6):
       - `isCairoTruckBanActive(lat, lng, vehicleWeightKg, currentTime?)`: Returns `{ banned: boolean, nightWindow: boolean, message: string }`.
       - Cairo bounds: north 30.22, south 29.85, east 31.52, west 31.05. Heavy = 5000+ kg. Ban window 6AM-midnight.

    8. Create lib/upload-queue.ts:
       - `queuePhotoUpload(fileUri, metadata: { type: 'loading'|'pod'|'damage', entityId: string })`: Write upload record to PowerSync.
       - `processUploadQueue()`: Read pending uploads from SQLite, upload to Supabase Storage (R2), mark as uploaded. Handle failures with retry count.
       - `getPendingUploadCount()`: Return count of pending uploads.
       - Store file URIs in SQLite, NOT base64 (anti-pattern from RESEARCH.md).

    9. Create truck-ban.test.ts with the 4 behavior tests above.

  <action>
    1. Create stores/route.ts -- `useRouteStore`:
       - State: `activeRoute: RouteData | null`, `stops: RouteStop[]`, `currentStopId: string | null`, `mapView: 'map' | 'list'`
       - Derived: `currentStop` (computed from stops + currentStopId), `completedCount`, `pendingCount`, `progress`
       - Actions:
         - `loadRoute(routeId)`: Query PowerSync for route + route_stops, set state.
         - `setCurrentStop(stopId)`: Set current stop.
         - `updateStopStatus(stopId, status)`: Update stop status in PowerSync + local state. Status: 'pending' | 'en_route' | 'arrived' | 'completed' | 'failed' | 'skipped'.
         - `recordArrival(stopId, lat, lng)`: Write arrival timestamp + GPS to PowerSync.
         - `toggleMapView()`: Toggle between 'map' and 'list'.
         - `skipStop(stopId, reason?)`: Move stop to end, recalculate ETAs, update status to 'skipped'.
       - Stop types: `{ id, route_id, delivery_id, stop_order, customer_name, address, lat, lng, status, eta, notes, unloading_method, contact_phone, delivery_window_start, delivery_window_end, ppe_required, access_instructions, previous_delivery_notes, site_photos }`

    2. Create stores/delivery.ts -- `useDeliveryStore`:
       - State: `activeDelivery: Delivery | null`, `items: DeliveryItem[]`, `unloadingStartedAt: string | null`, `unloadingDuration: number` (seconds, updated by timer)
       - Actions:
         - `loadDelivery(deliveryId)`: Query PowerSync for delivery + delivery_items.
         - `confirmItem(itemId)`: Set item status to 'delivered', quantity_delivered = quantity_expected.
         - `adjustQuantity(itemId, quantity, reason)`: Set partial delivery with reason code.
         - `flagDamage(itemId, notes, photoUri)`: Mark item as damaged with photo.
         - `startUnloadingTimer()`: Record start time, begin interval counter.
         - `stopUnloadingTimer()`: Stop timer.
         - `completeDelivery()`: Validate all items have status, write to PowerSync.
         - `allItemsResolved`: boolean computed (every item has a status).
       - DeliveryItem status: 'pending' | 'delivered' | 'partial' | 'damaged' | 'refused'.
       - Partial delivery reason codes: 'damaged_at_warehouse' | 'not_loaded' | 'customer_request' | 'other'.

    3. Create stores/loading.ts -- `useLoadingStore`:
       - State: `routeId: string | null`, `scanResults: ScanResult[]`, `truckPhotoUri: string | null`, `cargoPhotoUri: string | null`, `weightExpected: number`, `weightActual: number | null`, `signatureUrl: string | null`, `confirmed: boolean`
       - Derived: `totalExpected`, `totalScanned`, `shortItems` (scanned < expected), `weightVariance`, `isOverweight(gvwr)`, `canDepart` (all items checked + photos + weight + signature + confirmed).
       - Actions:
         - `initLoading(routeId, items[])`: Set up load plan from route items.
         - `recordScan(barcode, itemId, matched)`: Add scan result. Green checkmark match, red alert mismatch.
         - `manualCheck(itemId)`: For items without barcodes.
         - `setTruckPhoto(uri)` / `setCargoPhoto(uri)`.
         - `setWeight(kg)`.
         - `setSignature(dataUrl)`.
         - `setConfirmed(val)`.
         - `submitLoadVerification()`: Write to PowerSync load_verifications table.
       - ScanResult: `{ barcode, itemId, matched, timestamp }`.
       - Weight tolerance: +/- 2%. Beyond truck GVWR = block.

    Follow the same Zustand patterns as shift.ts (direct db.execute/db.getAll calls, no async middleware).
  </action>
