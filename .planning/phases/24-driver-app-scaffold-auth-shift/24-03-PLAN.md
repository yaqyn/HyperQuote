1. Create `src/stores/auth.ts` (Zustand):
   - State: `session: Session | null`, `isAuthenticated: boolean`, `driverProfile: DriverProfile | null`, `hasBiometric: boolean`, `hasPin: boolean`, `authStep: 'phone' | 'otp' | 'pin-setup' | 'pin-verify' | 'biometric-prompt' | 'biometric-verify' | 'authenticated'`
   - Actions: `setSession(session)`, `clearSession()`, `setDriverProfile(profile)`, `setHasBiometric(v)`, `setHasPin(v)`, `setAuthStep(step)`, `logout()` (clears all + calls supabase.auth.signOut)
   - `initAuth()`: check supabase.auth.getSession, set session if exists, check if PIN exists in Preferences, check if biometric enrolled
   - Listen to supabase.auth.onAuthStateChange to auto-update session

2. Create `src/lib/biometric.ts`:
   - `isBiometricAvailable()`: NativeBiometric.isAvailable({ useFallback: false }), returns { isAvailable, biometryType }
   - `enrollBiometric(phone, pinHash)`: NativeBiometric.setCredentials({ username: phone, password: pinHash, server: 'hyperquote-driver' })
   - `verifyBiometric()`: NativeBiometric.verifyIdentity({ reason, title: 'HyperQuote Driver', useFallback: true }), then getSecureCredentials({ server: 'hyperquote-driver' }), returns { username, password } (phone + pinHash)
   - `deleteBiometric()`: NativeBiometric.deleteCredentials({ server: 'hyperquote-driver' })
   - All functions wrapped in try/catch, return null on failure instead of throwing

3. Create `src/lib/pin.ts`:
   - `hashPin(pin: string)`: SHA-256 hash of pin (using SubtleCrypto), returns hex string
   - `verifyPin(pin: string, hash: string)`: hash input and compare to stored hash
   - `storePinHash(hash: string)`: Preferences.set({ key: 'hq-pin-hash', value: hash })
   - `getPinHash()`: Preferences.get({ key: 'hq-pin-hash' }), returns string | null
   - `clearPinHash()`: Preferences.remove({ key: 'hq-pin-hash' })

4. Create `src/components/shared/DriverButton.tsx`:
   - React Aria `Button` wrapper styled for driver app
   - Variants: primary (blue bg, white text, full width, 56px height), secondary (white bg, blue border, 48px), danger (red)
   - All have min-height 56px (touch target), rounded-xl, font medium
   - Haptic feedback on press via @capacitor/haptics
   - Loading state with spinner
   - Disabled state with reduced opacity

5. Create `src/components/shared/DriverCard.tsx`:
   - White card with rounded-2xl, shadow-sm, p-4
   - Dark mode variant via data-theme
   - Slot for header, body, footer
