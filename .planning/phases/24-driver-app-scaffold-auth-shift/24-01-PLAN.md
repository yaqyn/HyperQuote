   - State: `theme: 'light' | 'dark'`, `setTheme`, `toggleTheme`
   - Auto dark mode logic: check hour, 18-6 = dark (night shift default)
   - Persist to `@capacitor/preferences` key 'hq-theme'
   - Apply `data-theme` attribute on `<html>` element

3. Create `src/i18n/config.ts`:
   - Init i18next with react-i18next
   - Default language: 'ar' (Arabic primary)
   - Namespaces: ['driver']
   - Resources: inline import from locales
   - Arabic-Indic numeral formatting via i18next interpolation

4. Create `src/i18n/locales/ar/driver.json`:
   - Keys for: login (phone, otp, pin, biometric), shift (vehicle, inspection, odometer, gpsConsent), home (route, stops, distance, weight, start), common (confirm, cancel, back, next, retry, noConnection, loading)
   - All values in Arabic

5. Create `src/i18n/locales/en/driver.json`:
   - Same keys as Arabic, English values

6. Create `src/router.ts`:
   - `createRouter` from `@tanstack/react-router`
   - Import route tree from routes
   - Export `router` instance
   - Use `createRootRoute`, `createRoute` for /login, /home, /shift-start

   - `src/routes/home.tsx` — placeholder "Home" text, will be built in Plan 04
   - `src/routes/shift-start.tsx` — placeholder "Shift Start" text, will be built in Plan 04
