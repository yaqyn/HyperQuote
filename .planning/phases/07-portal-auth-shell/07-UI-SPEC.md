# Phase 7 — UI Design Contract

> Visual and interaction contract for Portal Auth + Shell: authentication gate, spatial canvas, AI chat input, glass window navigation, role toggle, floating AI button. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn excluded per CLAUDE.md -- React Aria mandated) |
| Preset | not applicable |
| Component library | React Aria Components ^1.16.0 |
| Icon library | Lucide React |
| Font | Inter (Latin), IBM Plex Sans Arabic (Arabic), Geist Mono (all numbers) |

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding |
| sm | 8px | Compact element spacing, badge internal padding |
| md | 16px | Card padding, button gaps, canvas horizontal padding (mobile) |
| lg | 24px | Navigation button gap below chat, window header px, section padding |
| xl | 32px | Avatar/profile popover spacing |
| 2xl | 48px | Page-level vertical padding |
| 3xl | 64px | Major section breaks |

Exceptions: 44px minimum touch target for close buttons, floating AI button, notification bell, profile avatar tap area. 56px AI chat input height. 56px glass window header bar height. 36px role toggle height. 40px send button circle. 64px navigation button height. 380px floating AI panel width. 640px AI chat input max-width (desktop). 720px AI chat + greeting max-width (per CONTEXT.md "What to Build"). 1200px glass window max-width. 90vh glass window max-height. 400px PWA install banner max-width. 20px -- chat input horizontal padding, midpoint between md (16px) and lg (24px) for optical balance at 56px input height where 16px feels cramped and 24px wastes space.

## Typography

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body / Label / Muted | 14px | 400 | 1.5 | Inter / IBM Plex Sans Arabic |
| Small / Meta / Badge | 12px | 400 (meta) / 600 (badge) | 1.5 (meta) / 1 (badge) | Inter / IBM Plex Sans Arabic / Geist Mono (badge) |
| Navigation button label | 16px | 600 | 1.2 | Inter / IBM Plex Sans Arabic |
| Heading (window title, greeting) | 18px | 600 | 1.2 | Inter / IBM Plex Sans Arabic |

Distinct sizes: 12px, 14px, 16px, 18px (4 sizes, 2 weights: 400 + 600).

Notes:
- Portal uses 14px base (not 16px -- that is website-only per UI-VISION.md Section 4).
- Muted text uses 14px at reduced opacity or `var(--color-text-muted)` color -- NOT a separate font size.
- Window subtitle uses 14px at `var(--color-text-muted)` color, not a smaller size.
- Geist Mono for ALL numeric data: badge counts, timestamps, urgent item counts.
- IBM Plex Sans Arabic max weight 700. Never use Inter 800/900 in bilingual contexts.

## Color

| Role | Value (Light) | Value (Dark) | Usage |
|------|---------------|--------------|-------|
| Dominant (60%) | `var(--color-base)` #FFFFFF | `var(--color-base)` #09090B | Canvas background -- the emptiness IS the design |
| Secondary (30%) | `var(--color-card)` #FFFFFF | `var(--color-card)` #27272A | Glass window panels, navigation buttons, chat input bg, profile popover |
| Accent (10%) | `var(--color-primary)` #2563EB | `var(--color-primary)` #3B82F6 | See reserved-for list below |
| Destructive | `var(--color-error)` #DC2626 | `var(--color-error)` #F87171 | Sign out confirmation text, cancel/stop button tint |

Accent reserved for:
- Send button circle (blue bg, white ArrowUp icon)
- Sparkles icon in chat input (at 50% opacity)
- Navigation button icons (ShoppingBag, Store -- 24px, blue)
- Active segment of role toggle (blue bg, white text)
- Notification bell unread dot
- "Install" button in PWA banner
- Floating AI button (44px circle, blue bg)
- Chat input focus border (1.5px `var(--color-primary)`)
- Focus ring: `0 0 0 3px rgba(37,99,235,0.1)`
- User chat messages (blue bg, white text)

Glass window surfaces:
- Window tier: `backdrop-blur-xl bg-[rgba(255,255,255,0.80)] dark:bg-[rgba(0,0,0,0.80)]`
- Elevated tier: `backdrop-blur-2xl bg-[rgba(255,255,255,0.90)] dark:bg-[rgba(0,0,0,0.90)]`
- Backdrop overlay: `bg-black/20 dark:bg-black/40`
- Elevated overlay: `bg-black/40`

Canvas recede state (when window open):
- `scale(0.96)`, `blur(2px)`, `opacity: 0.5`, tween 300ms

## Component Inventory

### 1. Auth Gate (PORT-01)
- `beforeLoad` route guard in `_portal.tsx` layout route
- Server-side SSO cookie check (`hq-external-session`)
- Redirect: `hyperquote.net?login=portal&redirect={encoded_path}`
- Internal-only user error page: heading + "Go to Internal App" button
- No visual component -- zero flash of unauthenticated content

### 2. Spatial Canvas (PORT-02)
- Full viewport, `var(--color-base)` background, completely empty
- No gradients, no patterns, no decorations
- Welcome greeting: centered, ~40% from top, spring animation on load
  - Time-aware: morning (5-12), afternoon (12-17), evening (17-22), night (22-5)
  - AR: "صباح الخير، أحمد" / EN: "Good morning, Ahmed"
  - Urgent items: "{count} items need your attention" with AlertCircle icon (Lucide)
  - Greeting fades after 3s to opacity 0.4 (visible but receded)
- Lion watermark: NOT on portal canvas (only CEO + internal per UI-VISION.md)

### 3. AI Chat Input
- Centered horizontally, below greeting
- Max-width: 640px (CONTEXT.md success criteria) / 720px (CONTEXT.md "What to Build" -- use 640px as the input width, 720px as the containing area)
- Height: 56px, rounded-2xl, border 1px `var(--color-border)`, bg `var(--color-card)`, shadow-sm
- Padding: px-20px
- Sparkles icon: 20px at inline-start, `var(--color-primary)` at 50% opacity
- Send button: 40px circle, blue bg, ArrowUp icon (Lucide). Opacity 0.3 when empty, 1.0 when text present
- Placeholder rotation every 8s (CSS opacity crossfade):
  - EN: "What do you need today?" / "Try: I need 500 bags of cement" / "Try: Reorder my last purchase" / "Try: What's the status of my order?"
  - AR: "ماذا تحتاج اليوم؟" / "جرّب: أحتاج ٥٠٠ كيس أسمنت" / "جرّب: أعد طلبي الأخير" / "جرّب: ما حالة طلبي؟"
- Focus state: border `var(--color-primary)` 1.5px, shadow `0 0 0 3px rgba(37,99,235,0.1)`, placeholder stops rotating

### 4. Chat Message Area
- Grows above input when messages exist
- User messages: blue bg (`var(--color-primary)`), white text, rounded-2xl
- AI messages: `var(--color-card)` bg, border 1px `var(--color-border)`, rounded-2xl
- Typing indicator: "HyperQuote is thinking..." / "هايبر كوت يفكر..."
- Cancel: send button becomes stop button (Square icon, red tint via `var(--color-error)`). AbortController.
- Rich message types deferred to Phase 8 -- this phase renders plain text only

### 5. Navigation Buttons (below chat, mt-24px)
- Two glass-style cards side by side, gap 16px
- Each: h-64px, rounded-2xl, `var(--color-card)` bg, border 1px `var(--color-border)`, shadow-sm
- "Orders": ShoppingBag 24px blue + "Orders" / "الطلبات" Inter 600 16px + badge count (Geist Mono 12px 600)
- "Market": Store 24px blue + "Market" / "السوق" Inter 600 16px. No badge.
- Hover: translateY(-2px), shadow-lg. Transition 200ms ease.
- Click: opens glass window via URL navigation
- Mobile (<480px): stack vertically, full width

### 6. Role Toggle (supplier users only)
- Position: top-right area of canvas
- React Aria ToggleButtonGroup: "Customer" / "Supplier" segments
- 200px total, h-36px, rounded-full
- Active: blue bg, white text. Inactive: transparent, `var(--color-text-muted)`
- Sliding indicator animation (CSS transition, not Motion -- per UI-VISION.md)
- On switch: all windows close (tween 150ms), canvas resets, navigation buttons change
  - Customer: "Orders" (ShoppingBag) + "Market" (Store)
  - Supplier: "Stock" (Package) + "Purchase Orders" (ClipboardList)
- Zustand store: `activeRole: 'customer' | 'supplier'`
- TanStack Query keyed by role
- Mobile: moves inside profile menu (not floating)

### 7. Header Controls (top inline-end)
- Notification bell: Bell icon 20px, `aria-label="Notifications"` (EN) / `aria-label="الإشعارات"` (AR). Blue dot (8px circle) if unread. Opens `/notifications` window.
- Profile avatar: 32px circle. Click opens React Aria Popover:
  - Name (Inter 600 14px), Company (Inter 400 14px `var(--color-text-muted)`)
  - Menu items: Settings, Documents, Support, Language, Theme, Sign Out
  - Menu item height: 44px touch target
  - Popovers use CSS transitions (NOT Motion -- per React Aria gotcha)
- Sign Out: inline confirmation "Are you sure?" with "Keep me signed in" (default text) + "Sign Out" (red text `var(--color-error)`)

### 8. Glass Window System (PORT-17)
- Opens via URL route navigation (e.g., `/orders`)
- Spring enter: opacity 0->1, scale 0.98->1, stiffness 200, damping 20
- Tween exit: opacity 1->0, duration 150ms
- Max-width: 1200px, max-height: 90vh, centered
- Surface: `var(--color-card)` bg, backdrop-blur-xl, 80% opacity, rounded-3xl, shadow-2xl
- Border: 1px `var(--color-border)` at 50% opacity
- Header bar: h-56px, px-24px, border-bottom 1px `var(--color-border)`
  - Left: title (Inter 600 18px) + optional subtitle (Inter 400 14px `var(--color-text-muted)`)
  - Right: close button (X 24px, 44px touch target, `var(--color-text-muted)`, hover `var(--color-text)`), `aria-label="Close"` (EN) / `aria-label="إغلاق"` (AR)
- Escape closes. Click outside (on dimmed canvas) closes.
- Deep-linking: `/orders` opens Orders window directly. Browser back closes window.
- Canvas recede: scale 0.96, blur(2px), opacity 0.5, tween 300ms
- Canvas restore: reverse on window close
- Window state preservation: Zustand keyed by window name (scroll position, active tab, form values, filters, expanded sections). Session-scoped, cleared on logout.
- Mobile (<768px): full-screen (100vw, 100vh), slides up from bottom, no rounded corners, swipe right/back to close

### 9. Elevated Layer (modals over windows)
- Stronger glass: backdrop-blur-2xl, 90% opacity, shadow-3xl
- Overlay: bg-black/40
- Focus trapped (React Aria Modal with `isKeyboardDismissDisabled`)
- Escape closes elevated only (window stays open)
- Handle Escape via hotkeys abstraction, not React Aria's built-in dismiss

### 10. Floating AI Button (when windows open)
- 44px circle, blue bg, Sparkles 20px white
- Position: bottom-right (bottom-left in RTL), 16px from edges
- Spring entrance after window opens (delay 200ms)
- Click: opens mini AI chat panel
  - 380px width, 60vh max-height, anchored bottom-right (bottom-left RTL)
  - Elevated glass: backdrop-blur-2xl, bg-white/90 dark:bg-black/90, rounded-2xl, shadow-2xl
  - Compact chat input (44px height) + scrollable message area + close button (X 16px)
  - Context-aware greeting: "I see you're looking at Orders -- need help?" / "أرى أنك تتصفح الطلبات -- هل تحتاج مساعدة؟"
- Ctrl+J toggles from anywhere
- Auto-closes when parent window closes

### 11. PWA Install Banner
- Triggers after 3rd visit (localStorage counter)
- Position: bottom center, mb-16px from viewport bottom
- `var(--color-card)` bg, rounded-xl, shadow-md, max-width 400px
- Content: HyperQuote icon 24px + "Install HyperQuote for quick access" / "ثبّت هايبر كوت للوصول السريع" Inter 400 14px + "Install" button (blue, h-32px) + close (X 16px)
- Dismissible. Once dismissed or installed, never shows again (localStorage flag).

### 12. Offline Banner
- Subtle top banner when connection drops
- Chat input disabled, placeholder: "Chat unavailable offline" / "الدردشة غير متاحة بدون اتصال"
- Windows show cached data with "Showing cached data" / "عرض بيانات مخزنة" label
- Mutations disabled -- buttons show tooltip "You're offline" / "أنت غير متصل" on hover

## Keyboard Shortcuts

| Key | Action | Condition |
|-----|--------|-----------|
| `/` | Focus AI chat input | No text input focused |
| `Escape` | Close topmost layer | Always |
| `O` | Open Orders window | No text input focused |
| `M` | Open Market window | No text input focused |
| `N` | Open Notifications window | No text input focused |
| `Ctrl+J` | Toggle floating AI panel | Always |

Implementation: `@tanstack/react-hotkeys` (0.8.3) wrapped behind `useShortcut()` abstraction. `{ enabled: !isMenuOpen }` on arrow key hotkeys to avoid ListBox/Menu conflicts.

| Profile popover | CSS transition (React Aria default) | CSS transition (React Aria default) |
| PWA banner | Tween: opacity 0->1, y 16->0, 300ms | Tween: opacity 1->0, 150ms |

## Accessibility Contract

- All interactive elements: 44px minimum touch target
- Focus visible: 2px offset ring using `var(--color-primary)` at 50% opacity
- Glass windows: React Aria Modal (focus trap, aria-modal, aria-labelledby)
- Profile popover: React Aria Popover (auto-dismiss, arrow key navigation)
- Role toggle: React Aria ToggleButtonGroup (aria-pressed, keyboard navigation)
- Chat input: `role="textbox"`, `aria-label` for screen readers
- Notification bell: `aria-label="Notifications"` (EN) / `aria-label="الإشعارات"` (AR)
- Close window button: `aria-label="Close"` (EN) / `aria-label="إغلاق"` (AR)
- Keyboard navigation: all shortcuts documented, all focusable elements reachable via Tab
- Screen reader announcements: window open/close, role switch, offline status
- RTL: all logical properties (ps-/pe-/ms-/me-), `dir="rtl"` on `<html>`
