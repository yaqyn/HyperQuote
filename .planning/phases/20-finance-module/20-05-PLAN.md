**PDCGridView.tsx** — Cheque table (Section 5.4 PDC Grid):
- Columns: # (row number), Cheque No, Customer, Bank, Amount (CurrencyCell), Maturity Date, Status (StatusBadge), Actions
- Status color coding: Received=blue (bg-blue-50), Deposited=orange (bg-orange-50), Cleared=green (bg-green-50), Bounced=red (bg-red-50), Re-presented=orange, Written Off=gray, Replaced=gray
- Context-dependent action buttons per row using getValidTransitions from cheque-state-machine.ts:
  - Received: [Deposit]
  - Deposited: [Clear] [Bounce]
  - Bounced: [Re-present] [Write Off] [Replace]
  - Re-presented: [Clear] [Bounce]
- [Bounce] action opens BounceHandlingModal
- Summary footer row: "Received: EGP X | Deposited: EGP Y | Cleared: EGP Z | Bounced: EGP W" — all CurrencyCell
- Sortable by maturity date (default), amount, customer
- Filter by status dropdown
- Batch actions: select multiple -> [Batch Deposit] [Batch Clear]

**BounceHandlingModal.tsx** — Bounce workflow (React Aria Dialog):
- Shows cheque details: Cheque #, Customer, Amount, Bank
- Reason dropdown: Insufficient funds, Signature mismatch, Account closed, Post-date not reached, Other
- Warning banner: "Bouncing this cheque will: (1) Reverse accounting entry (2) Add EGP X back to AR (3) Place customer on credit hold (4) Trigger legal notification"
- Action buttons: [Re-present] [Request Replacement] [Write Off] [Escalate to Legal]
- On confirm: calls updateChequeStatus with status='bounced' + reason
- Shows success state with summary of actions taken
