# Phase 15 — UI Design Contract

> Visual and interaction contract for Internal Platform Shell: auth gate, spatial canvas, 11-module icon strip, glass windows with hotkeys, command palette, notifications, mobile layout, activity feed infrastructure. Generated by gsd-ui-researcher.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (shadcn excluded per CLAUDE.md -- React Aria mandated) |
| Preset | not applicable |
| Component library | React Aria Components ^1.16.0 |
| Icon library | Lucide React |
| Font | Inter (Latin), IBM Plex Sans Arabic (Arabic), Geist Mono (all numbers) |

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge internal padding |
| sm | 8px | Compact element spacing, icon strip icon gap, notification dot offset |
| md | 16px | Card padding, button gaps, mobile canvas card padding, mobile card grid gap |
| lg | 24px | Window header px, section padding, icon strip vertical padding |
| xl | 32px | Layout gaps, canvas greeting vertical offset |
| 2xl | 48px | Page-level vertical padding, icon strip width |
| 3xl | 64px | Major section breaks |

Exceptions: 44px minimum touch target for all interactive elements (close buttons, icon strip icons, mobile cards, notification bell). 56px glass window header bar height. 48px icon strip width (sidebar). 90vh/90vw glass window dimensions on desktop. 600px command palette max-width. 400px command palette results max-height. 20px module icon size in window header. 24px icon strip icon size. 8px notification unread dot diameter.

## Typography

| Role | Size | Weight | Line Height | Font |
|------|------|--------|-------------|------|
| Body / Label | 14px | 400 | 1.5 | Inter / IBM Plex Sans Arabic |
| Small / Meta / Badge | 12px | 400 (meta) / 600 (badge) | 1.5 (meta) / 1 (badge) | Inter / IBM Plex Sans Arabic / Geist Mono (badge counts) |
| Module name (window header, icon tooltip) | 16px | 600 | 1.2 | Inter / IBM Plex Sans Arabic |
| Heading (greeting, section titles) | 20px | 600 | 1.2 | Inter / IBM Plex Sans Arabic |

Distinct sizes: 12px, 14px, 16px, 20px (4 sizes, 2 weights: 400 + 600).

Notes:
- Internal app uses 14px base (not 16px -- that is website-only per tokens.css).
- Geist Mono for ALL numeric data: urgent item counts, badge counts, timestamps, notification time.
- IBM Plex Sans Arabic max weight 700. Never use Inter 800/900 in bilingual contexts.
- Greeting heading bumped to 20px (vs portal 18px) because the internal app has more vertical real estate without the chat input.

Accent reserved for:
- Active module icon in icon strip (blue tint on icon, not bg)
- Notification unread dot (8px circle, solid blue)

- Elevated overlay: `bg-black/40`

Canvas recede state (when window open):
- `scale(0.96)`, `blur(2px)`, `opacity: 0.5`, tween 300ms

## Component Inventory

### 1. Auth Gate (INT-01)
- `beforeLoad` route guard in `_internal.tsx` layout route
- Server-side cookie check: `hq-internal-session` cookie
- Pool check: verify user belongs to internal auth pool (not customer/supplier)
- Reject: redirect to website login or show "Access denied" page
- External user error page: heading + "Go to Customer Portal" button
- No visual component -- zero flash of unauthenticated content

### 2. Spatial Canvas (INT-02)
- Full viewport, `var(--color-base)` background, completely empty
- No gradients, no patterns, no decorations, NO KPI cards, NO metrics, NO charts
- Welcome greeting: centered, ~40% from top, spring animation on load
  - Time-aware: morning (5-12), afternoon (12-17), evening (17-22), night (22-5)
  - AR: "صباح الخير، أحمد" / EN: "Good morning, Ahmed"
  - With urgent items: "Good morning, Ahmed -- 3 items need attention" with subtle emphasis on count
  - Count uses Geist Mono, Arabic-Indic numerals in AR locale
- Lion watermark: yes on internal canvas (per UI-VISION.md), barely-perceptible opacity (3-5%)
- 1-2 contextual quick-action buttons based on role:
  - Sales rep: "View RFQ Inbox" / "عرض صندوق طلبات التسعير"
  - Warehouse: "Today's Receiving" / "استلام اليوم"
  - Finance: "Overdue Invoices" / "فواتير متأخرة"
  - Default: "Open Sales" / "فتح المبيعات"

### 3. Urgent Item Sources (6 aggregated)
- Server function: parallel queries, single aggregated count
- Sources:
  1. RFQs unassigned > 30 minutes
  2. Quotes expiring within 24 hours
  3. Approvals pending for this user
  4. Deliveries with problems (red status)
  5. Invoices overdue > 60 days (finance role only)
  6. SLA breaches in progress
- Each source contributes to total count, not individually displayed on canvas
- Stale time: 60s (urgent data, refresh frequently)

### 4. Icon Strip (INT-03)
- Position: left edge (LTR) / right edge (RTL), always visible
- Width: 48px, full viewport height
- Background: transparent (no bg, no border -- just icons floating on canvas edge)
- 11 module icons, vertically centered, gap 8px between icons
- Each icon: 24px Lucide, `var(--color-text-muted)`, 44px touch target (centered)
- Active state: `var(--color-primary)` tint on icon
- Hover state: `var(--color-text)` color, no bg change
- Tooltip on hover: module name (React Aria TooltipTrigger, 200ms delay)
- Permission-filtered: if employee lacks access, icon does not render, hotkey does not register

| Position | Icon (Lucide) | Module | Hotkey |
|----------|--------------|--------|--------|
| 1 | `Tag` | Sales | `S` |
| 2 | `ShoppingCart` | Procurement | `P` |
| 3 | `ClipboardList` | Orders/Operations | `O` |
| 4 | `Warehouse` | Warehouse | `W` |
| 5 | `Banknote` | Finance | `F` |
| 6 | `Truck` | Dispatch | `D` |
| 7 | `Headset` | Customer Service | `C` |
| 8 | `Users` | HR | `H` |
| 9 | `Settings` | Admin | `A` |
| 10 | `BarChart3` | Reports | `R` |
| 11 | `Sparkles` | AI | `I` |

- Bottom of icon strip: notification bell (Bell, 20px, 44px target) with unread dot, profile avatar (32px circle)

### 5. Glass Windows (INT-04)
- Opens via URL route navigation (e.g., `/sales`, `/procurement`)
- Spring enter: opacity 0->1, scale 0.95->1, stiffness 200, damping 20
- Tween exit: opacity 1->0, scale 1->0.98, duration 200ms, easeIn
- Dimensions: ~90vw x ~90vh on desktop, 100% on mobile
- Surface: `backdrop-blur-xl bg-[rgba(255,255,255,0.80)] dark:bg-[rgba(0,0,0,0.80)]`
- Border: 1px `var(--color-border)` at 50% opacity
- Rounded: `rounded-xl` (8px)
- Shadow: `shadow-md`
- Window header: 56px height, px-24px
  - Inline-start: module icon (Lucide, 20px, `var(--color-text-muted)`) + module name (Inter 600 16px, `var(--color-text)`), gap 8px
  - Inline-end: close button (Lucide X, 20px icon, 44px touch target, `var(--color-text-muted)`, hover `var(--color-text)`)
  - Bottom border: 1px `var(--color-border)` at 50% opacity
- Scrollable content within window
- Mobile: 100vw x 100vh, no rounded corners, slide up from bottom

### 6. Window State Preservation
- Zustand store keyed by module name (e.g., `windowStates.sales`, `windowStates.procurement`)
- Preserved: scroll position, active tab/sub-view, form input values, step progress, selected filters, expanded/collapsed sections
- On hotkey swap: current window state saved, new window opens with restored state (or fresh if first visit)
- No loading delay on restore: TanStack Query cache provides instant data
- Session-scoped: cleared on logout or browser close
- Auto-saved form drafts (server-persisted via `saveDraft()`) are separate -- drafts survive across sessions
- `skipHydration: true` + `rehydrate()` in useEffect to avoid SSR mismatch

### 7. Hotkey System
- `useShortcut()` abstraction (already exists in portal, copy to internal app or extract to shared package)
- Single-key hotkeys: S, P, O, W, F, D, C, H, A, R, I
- Keyboard scope state machine via @xstate/store (<1KB):
  - `Canvas` scope: all hotkeys active
  - `Panel` scope: Escape active, module hotkeys active (for swapping), text input hotkeys disabled
  - `Input` scope: all hotkeys disabled (user typing in text field)
- Scope transitions: Canvas -> Panel (window opens), Panel -> Input (text field focused), Input -> Panel (text field blurred), Panel -> Canvas (window closes)
- Same hotkey while window open: if same module, close window (toggle). If different module, crossfade swap.
- Escape: close topmost layer (elevated first, then window, then nothing)
- `isKeyboardDismissDisabled` on all React Aria Dialogs -- Escape handled by hotkeys system only

### 8. Command Palette (INT-05)
- Trigger: Ctrl+K (Cmd+K on Mac)
- Built from React Aria `Autocomplete` + `Dialog` + `Menu`
- Elevated glass: `backdrop-blur-2xl bg-[rgba(255,255,255,0.90)] dark:bg-[rgba(0,0,0,0.90)]`
- Max-width: 600px, centered horizontally, ~30% from top
- Search input: 14px Inter, px-16px, py-12px, border-bottom 1px `var(--color-border)`
  - Placeholder: "Search or jump to..." / "ابحث أو انتقل إلى..."
  - Lucide `Search` icon 16px inline-start, `var(--color-text-muted)`
- Results area: max-height 400px, overflow-y auto, py-8px
- Result groups: "Entities", "Actions", "Modules", "Recent"
  - Group header: 12px 600 `var(--color-text-muted)` uppercase, px-16px, py-4px
  - Result item: 14px 400, px-16px, h-40px, keyboard-navigable
  - Active item: `var(--color-subtle)` bg, 2px inline-start border `var(--color-primary)`
  - Each item: icon (16px) + label + meta text (12px `var(--color-text-muted)`) right-aligned
- fuse.js fuzzy search across: entities (orders, quotes, customers, suppliers, products), actions, module navigation, recent items
- Permission-filtered results
- Keyboard: arrow keys navigate, Enter selects, Escape closes
- `isKeyboardDismissDisabled` on Dialog

### 9. Notifications Window (INT-06)
- Bell icon: top area of icon strip or canvas corner, 20px, `var(--color-text-muted)`
- Unread dot: 8px circle, `var(--color-primary)`, positioned top-right of bell icon
- Click opens notifications as a glass window (same pattern as modules, not a popover)
- Grouped by time: "Today" / "اليوم", "Yesterday" / "أمس", "Older" / "أقدم"
- Each notification: icon (16px, type-specific) + title (14px 400) + timestamp (12px Geist Mono `var(--color-text-muted)`) + action link
- Mark as read: click or explicit button
- Mark all read: header action
- Mute by type: overflow menu per notification
- Sources: system events, @mentions, approval requests, SLA warnings, delivery status changes
- Real-time via Supabase Realtime `postgres_changes`
- Empty state: "All caught up" / "لا توجد إشعارات جديدة" with CheckCircle icon

### 10. Mobile Layout (INT-07)
- No icon strip on mobile (<768px)
- Canvas shows module icons as tappable glass cards in a 2-column grid
- Each card: `var(--color-card)` bg, border 1px `var(--color-border)`, rounded-xl, shadow-sm
  - Module icon (24px, `var(--color-text-muted)`) + module name (14px 600) + badge count if applicable (Geist Mono 12px 600)
  - Min-height: 80px, padding 16px
  - Permission-filtered: cards don't render for unauthorized modules
- Grid gap: 16px, px-16px
- Tapping opens full-screen module view (100vw x 100vh, slide up)
- Back gesture: swipe from edge returns to canvas
- Top bar: greeting (truncated to first name), notification bell, profile avatar
- Search: magnifying glass icon in top bar (intentionally icon-only, 44px touch target, `aria-label="Search"` / `aria-label="بحث"`, React Aria TooltipTrigger on long-press for label discovery), opens full-screen search overlay (command palette adapted to mobile full-screen)
- Bottom safe area respected on all screens

### 11. Activity Feed / @Mentions / Handoff (INT-08)
- Shared component: `<ActivityFeed entityType="order" entityId={id} />`
- Renders on any entity (orders, quotes, customers, deliveries, tickets)
- Feed items:
  - Internal comment: blue left border (2px `var(--color-primary)`), user avatar (24px) + name (14px 600) + timestamp (12px Geist Mono) + body (14px 400)
  - External comment: gray left border (2px `var(--color-border)`), same layout
  - System event: no border, italic text, `var(--color-text-muted)`, smaller icon (16px)
- @mentions: `@` triggers autocomplete (React Aria Autocomplete), matched user gets `var(--color-subtle)` bg highlight in rendered text
- Role-aware routing: @mention notifies the mentioned user
- Input: text area at bottom of feed, 14px, `var(--color-card)` bg, border 1px `var(--color-border)`, rounded-lg
  - Toggle: "Internal" / "External" via React Aria ToggleButton (internal default, blue indicator for internal, gray for external)
  - Send button: ArrowUp icon, 32px circle, `var(--color-primary)` bg when text present, disabled state when empty
- "Hot Potato" escalation: unacknowledged mention after 30 min escalates to department manager (server-side, no UI in this phase beyond the notification it generates)
- Vacation delegation routing: server-side, no UI in this phase

## Loading, Empty, and Error States

**Loading:** Skeleton shimmer loaders matching expected content shape. No spinners. No "Loading..." text. Canvas greeting loads from server function (skeleton: two lines of text shimmer).

**Empty states:** Meaningful message + contextual CTA. Lion watermark at barely-perceptible opacity behind message. Example: module placeholder shows "Coming soon" with lion.

**Error states:**
- Failed data fetch: inline error message + "Retry Request" button
- Failed action: toast notification (minimal, top of viewport, stacked)
- Network offline: subtle top banner "You're offline -- showing cached data" with auto-dismiss on reconnect
- Permission denied: redirect to canvas (no error page, no toast)

## Accessibility Contract

- All interactive elements: 44px minimum touch target
- Focus visible: 2px offset ring using `var(--color-primary)` at 50% opacity
- Glass windows: React Aria Modal (focus trap, aria-modal, aria-labelledby)
- Command palette: React Aria Dialog + Autocomplete + Menu (focus trap, keyboard navigation)
- Icon strip: `role="navigation"`, `aria-label="Module navigation"` (EN) / `aria-label="تنقل الأقسام"` (AR)
- Each icon: `aria-label="{module name}"`, tooltip on hover
- Notification bell: `aria-label="Notifications"` (EN) / `aria-label="الإشعارات"` (AR)
- Close button: `aria-label="Close"` (EN) / `aria-label="إغلاق"` (AR)
- Mobile search icon: intentionally icon-only (44px touch target), `aria-label="Search"` (EN) / `aria-label="بحث"` (AR), React Aria TooltipTrigger on long-press for visible label discovery on touch devices
- Activity feed: `role="feed"`, each item `role="article"`, `aria-label` for timestamp
- @mention autocomplete: React Aria Autocomplete (aria-expanded, aria-activedescendant)
- Keyboard navigation: all shortcuts documented, all focusable elements reachable via Tab
- Screen reader announcements: window open/close, module switch, notification count change
- RTL: all logical properties (ps-/pe-/ms-/me-), `dir="rtl"` on `<html>`
