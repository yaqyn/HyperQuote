   - Zustand store with `skipHydration: true`
   - State: `{ unreadCount: number; isWindowOpen: boolean; setUnreadCount: (n: number) => void; toggleWindow: () => void; closeWindow: () => void }`
   - Export `useNotificationStore`

2. Create `apps/internal/src/lib/server/notifications.ts`:
   - `getNotifications` server function: returns mock notification array
   - Each notification: `{ id: string; type: 'system' | 'mention' | 'approval' | 'sla' | 'delivery'; title: string; body: string; createdAt: string; readAt: string | null; actionUrl?: string }`
   - Mock data: return 3 sample notifications spanning "today", "yesterday", "older" for development
   - `markNotificationRead` server function: accepts `{ id: string }`, returns `{ success: true }` (mock)
   - `markAllRead` server function: returns `{ success: true }` (mock)

3. Create `apps/internal/src/hooks/useRealtimeNotifications.ts`:
   - Props: `{ userId: string; enabled?: boolean }`
   - Creates Supabase client instance (import `createClient` from `@supabase/supabase-js`)
   - Subscribes to `postgres_changes` on `notifications` table, filter `user_id=eq.${userId}`
   - On INSERT event: invalidate TanStack Query cache key `['notifications']` via `queryClient.invalidateQueries({ queryKey: ['notifications'] })`
   - Also increment `unreadCount` in notification store
   - Cleanup: unsubscribe on unmount
   - If `!import.meta.env.VITE_SUPABASE_URL` (dev mode), skip subscription entirely (no-op)
   - Uses `useQueryClient` from `@tanstack/react-query` for cache invalidation

4. Create `apps/internal/src/components/shell/NotificationBell.tsx`:
   - Props: `{ hasUnread?: boolean; onPress: () => void }`
   - Renders `<Button>` from react-aria-components (NOT `<Link>` like portal -- internal notifications open a window, not navigate)
   - Bell icon from lucide-react (20px)
   - Unread dot: `absolute top-2 end-2 w-2 h-2 rounded-full bg-[var(--color-primary)]` (only if hasUnread)
   - Touch target: `w-11 h-11`
   - Styling: `text-[var(--color-text-muted)] hover:text-[var(--color-text)] transition-colors`
   - aria-label from `t('bell.label')`
   - No badge animation (spec says: no glow, no pulse, no animation on badge)
   - Notification count NOT SSR'd (client-side only via Skeleton or omit until query resolves, per Pitfall 7)

5. Create `apps/internal/src/components/shell/NotificationsWindow.tsx`:
   - Props: `{ isOpen: boolean; onClose: () => void }`
   - Uses `GlassWindow` from `@hyperquote/ui`
   - Header: "Notifications" title + "Mark all read" button (text-sm text-[var(--color-primary)])
   - Uses `useQuery({ queryKey: ['notifications'], queryFn: () => getNotifications() })` for data
   - Groups notifications by time:
     - "Today": `createdAt` is today
     - "Yesterday": `createdAt` is yesterday
     - "Older": everything else
   - Each section: `<h3>` header (text-xs font-semibold text-[var(--color-text-muted)] uppercase tracking-wide px-4 py-2) + list of items
   - Each notification item:
     - Icon by type: system (Bell), mention (AtSign), approval (CheckCircle2), sla (Clock), delivery (Truck) from lucide-react
     - Title (text-sm font-medium), body (text-xs text-muted, truncate single line), timestamp in Geist Mono (text-xs text-muted)
     - Unread indicator: `w-2 h-2 rounded-full bg-[var(--color-primary)]` at inline-start
     - Click: mark as read + navigate to actionUrl if present
     - Hover: `bg-[var(--color-primary)]/5`
   - Empty state: "No notifications" centered message with Bell icon (muted, 48px)
   - On open: dispatch `openPanel` to keyboard scope
   - On close: dispatch `closePanel` to keyboard scope
