   - Events:
     - `openPanel` -> scope: 'panel'
     - `closePanel` -> scope: 'canvas'
     - `focusInput` -> scope: 'input'
     - `blurInput` -> if currently 'input', check if panel was open (track `panelOpen: boolean` in context). If panelOpen, go to 'panel', else 'canvas'.
   - Context: `{ scope: 'canvas', panelOpen: false }`
   - `openPanel` also sets `panelOpen: true`, `closePanel` sets `panelOpen: false`
   - **IMPORTANT: `panelOpen` is a single boolean. This is safe because command palette and module window are mutually exclusive -- command palette closes the active module window on open, and module hotkeys are disabled while command palette is open (scope === 'panel'). Document this assumption with a comment in the store.**
