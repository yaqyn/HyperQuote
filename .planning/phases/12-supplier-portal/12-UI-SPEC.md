## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, cell inline padding |
| sm | 8px | Compact element spacing, table cell padding |
| md | 16px | Default element spacing, card padding |
| lg | 20px | KPI card padding (per FRONTEND.md 2.14) |
| xl | 24px | Section padding, drawer padding |
| 2xl | 32px | Layout gaps between sections |
| 3xl | 48px | Sticky bottom bar height (PO actions), CTA button height |

Exceptions:
- 44px: minimum touch target for primary action buttons (Upload Catalog, Add Product)
- 48px: PO action buttons (Confirm PO, Reject PO) per FRONTEND.md 2.12
- 480px: product edit drawer width (inline-end slide)
- 200px: minimum KPI card width per FRONTEND.md 2.14
- 300px: chart height per FRONTEND.md 2.14
- 50 items per page: stock table pagination

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `var(--color-base)` #FFFFFF / #09090B | Canvas background, window backgrounds |
| Secondary (30%) | `var(--color-surface)` #F8FAFC / #18181B | Table rows, KPI cards, drawer background, tab backgrounds |
| Accent (10%) | `var(--color-primary)` #2563EB / #3B82F6 | See reserved list below |
| Destructive | `var(--color-error)` #DC2626 / #F87171 | Reject PO button (outline), out-of-stock badge |

Accent reserved for:
- "Upload Catalog" primary CTA button
- "Save" button in product edit drawer
- "Submit for Review" button in catalog upload flow
- "Apply Changes" button in bulk update flow
- "Submit Invoice" button
- Role toggle active indicator (already implemented)
- Active tab indicator underline
- Inline edit focus ring
- Link text in empty states

Semantic data colors (NOT design colors):
- Green `var(--color-success)`: freshness < 24h, "Active" badge, "Confirmed" badge, "Approved" badge, "Paid" badge, positive trend arrow, confirm PO button, cell flash on successful inline edit
- Yellow `var(--color-warning)`: freshness 1-3 days, "Low Stock" badge, "Pending Review" badge, "Under Review" badge, medium confidence (70-90%)
- Red `var(--color-error)`: freshness > 3 days, "Out of Stock" badge, "Failed" badge, "Rejected" badge, "Disputed" badge, negative trend arrow, low confidence (< 70%)
- Gray `var(--color-text-muted)`: "Suppressed" badge, "Processing" badge

## Interaction Contracts

### Inline Edit (Stock Table)
1. Cell displays value in Geist Mono, read-only appearance
2. Click cell -> React Aria NumberField appears inline, auto-focused, value selected
3. Enter or blur -> PATCH to server immediately (no save button)
4. Success -> cell background flashes `var(--color-success-bg)` for 500ms, then fades
5. Error -> revert to previous value + Toast with error message
6. Tab moves to next editable cell in same row

### PO Confirm/Reject Flow
1. Per-line: React Aria Checkbox default checked
2. Uncheck -> "Reason" Select appears (Out of Stock, Partial Only, Price Changed, Lead Time Needed)
3. "Partial Only" -> NumberField appears (max = requested qty)
4. "Price Changed" -> NumberField + "Requires HyperQuote review" note
5. Sticky bottom bar: "Confirm PO" (green, 48px, flex-1) + "Reject PO" (red outline, 48px)
6. Confirm -> GlassElevated modal: "Confirm {N} of {M} items?" + Cancel/Confirm
7. Reject -> GlassElevated modal: TextArea "Why are you rejecting this PO?" + Cancel/Reject

### Catalog Upload Flow (4 steps)
1. Upload: GlassElevated modal, drag-and-drop zone, PDF/Excel/CSV, max 50MB
2. Processing: "AI is parsing your catalog..." with Skeleton/spinner
3. Review: two-column layout (original document left, extracted data right with ConfidenceBadge per row)
4. Submit: "Submit for Review" -> trusted suppliers auto-approved

### Bulk Price Update Flow (4 steps)
1. Download: "Download Current Prices" link generates CSV
2. Upload: user uploads modified CSV
3. Diff preview: BulkUpdateDiff shows changed values (old strikethrough red -> new green), unchanged rows grayed
4. Confirm: "Apply Changes" -> GlassElevated confirmation: "Update {N} prices and {M} stock quantities?"

### Product Edit Drawer
1. Trigger: "Edit" action in stock table row
2. Drawer slides from inline-end (RTL: left), 480px width, GlassElevated
3. Fields: Product name (read-only), Price (NumberField, required), MOQ (NumberField), Stock qty (NumberField), Lead time (NumberField + "days"), Region pricing (table if multi-region), Notes (TextArea)
4. "Save" (blue, 44px, full-width) at bottom, "Cancel" closes drawer
5. Close on Escape key

### Invoice Submission
1. ComboBox selects from confirmed/shipped POs without existing invoices
2. Line items auto-populate from selected PO (editable prices)
3. Subtotal/VAT(14%)/Total auto-calculated, displayed in Geist Mono 18px bold
4. If user total mismatches calculated total by > 1%: yellow warning banner
5. PDF upload required (drag-drop, max 10MB)

### Role Toggle (existing)
- Already implemented in `RoleToggle.tsx`
- On switch to supplier: navigate to `/`, canvas shows supplier buttons
- Supplier canvas buttons: "Stock & Pricing" (Package icon), "Purchase Orders" (ClipboardList + badge), "Analytics" (BarChart3)
- Keyboard shortcuts when supplier mode: S=Stock, P=Purchase Orders, A=Analytics

### Mobile Adaptation
- Tables become card lists (each row -> stacked card)
- Editable fields: tap opens inline edit
- Edit drawer -> full-screen sheet
- KPI cards: 2x2 grid
- Upload area: larger touch target
