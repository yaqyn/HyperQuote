## Interaction Contracts

### Role Toggle Behavior

- RoleToggle already exists in PortalHeader (built in Phase 7)
- On toggle to "Supplier": canvas greeting changes, NavButtons switch to supplier items, AI chat context switches
- Navigate to "/" on role switch (already implemented)
- Canvas shows supplier-specific greeting: "Good morning, {name}" + pending PO count
- Keyboard shortcuts change: S=Stock, P=Purchase Orders, A=Analytics

### Stock Table Inline Edit

1. Table renders with React Aria Table. 50 rows per page, paginated.
2. Price and Qty columns show current value in Geist Mono 14px.
3. Click on price/qty cell: cell transforms to React Aria NumberField (inline, no modal).
4. NumberField: same cell dimensions, border 1px var(--color-primary), focused state.
5. Currency prefix "EGP" for price cells (or suffix per locale).
6. On Enter or blur: PATCH `updateSupplierStock()` immediately.
7. **Success:** cell flashes var(--color-success-bg) for 500ms, value updates in place.
8. **Error:** revert to previous value + Toast "Failed to update. Try again."
9. On Escape: cancel edit, revert to original value, no save.
10. Tab key: save current cell, move focus to next editable cell in same row.

### Freshness Color Coding

- "Last Updated" column: relative time display (Geist Mono 12px).
- < 24h: text color var(--color-success).
- 1-3 days: text color var(--color-warning).
- > 3 days: text color var(--color-error).
- > 7 days: product auto-suppressed, "Suppressed" badge appears.

### Product Edit Drawer

1. Triggered by Pencil icon (16px) in Actions column.
2. Drawer slides from inline-end (right in LTR, left in RTL), 480px width.
3. Background: elevated glass (backdrop-blur-2xl bg-white/90 dark:bg-black/90).
4. Spring enter animation (stiffness 200, damping 20).
5. Tween exit animation (200ms, easeIn).
6. Product name: read-only (changes require HyperQuote review).
7. Fields: Price (NumberField, required), MOQ (NumberField), Stock qty (NumberField), Lead time (NumberField + "days" label), Region pricing table (if multi-region), Notes (TextArea).
8. "Save" button: blue bg, 44px height, full width at drawer bottom.
9. "Cancel": closes drawer, no save.
10. Escape closes drawer.

### Catalog Upload Flow

1. **Upload modal** (GlassElevated, isKeyboardDismissDisabled): drag-and-drop zone centered, accepts PDF/Excel/CSV, max 50MB. File type icons. "Browse files" link below drop zone.
2. **Processing state:** modal content becomes "AI is parsing your catalog..." with indeterminate progress indicator (blue spinner). Poll for completion.
3. **Review state:** two-column layout. Left: original document preview (PDF viewer / spreadsheet preview). Right: extracted data table with confidence score per row.
   - Confidence > 90%: green dot + score in Geist Mono 12px.
   - Confidence 70-90%: yellow dot + score.
   - Confidence < 70%: red dot + score + editable fields highlighted.
   - Each extracted field is editable (click to edit, React Aria TextField/NumberField).
4. **Submit:** "Submit for Review" button (blue bg, 48px). Trusted suppliers auto-approved. Toast: "Catalog submitted for review."

### Bulk Update Flow

1. "Bulk Update" button in toolbar opens BulkUpdateFlow.
2. Step 1: "Download Current Prices" link -- generates CSV of current stock data.
3. Step 2: Upload modified CSV. Drag-and-drop zone same pattern as catalog upload.
4. Step 3: Diff preview table. Changed values: old (red strikethrough) -> new (green). Unchanged rows grayed out (opacity 0.5).
5. Step 4: BulkConfirmModal: "Update {N} prices and {M} stock quantities?" + "Cancel" (outline) / "Apply Changes" (blue bg).
6. Toast: "{N} prices and {M} quantities updated."

### PO Inbox Navigation

- React Aria Tabs with 3 tabs: Pending Action, Confirmed, History.
- Tab bar: 44px height, active tab has 2px bottom border var(--color-primary).
- Pending Action tab: badge with count in Geist Mono 12px.
- PO cards sorted by urgency (oldest first).
- Response deadline: color-coded countdown (Geist Mono 14px 600).
  - > 4h remaining: var(--color-text).
  - < 4h remaining: var(--color-warning).
  - Expired: var(--color-error) + "Overdue" label.

### PO Detail View

1. Back button (ChevronLeft / ChevronRight for RTL) returns to inbox.
2. Header: PO reference (Geist Mono 14px), date, status badge, "From: HyperQuote" (anonymized).
3. Line items table: columns "#", "Product", "Qty Requested" (Geist Mono), "Unit Price" (Geist Mono), "Line Total" (Geist Mono), "Confirm" (per-line checkbox).
4. Each line has React Aria Checkbox. Unchecking reveals "Reason" Select:
   - "Out of Stock", "Partial Only", "Price Changed", "Lead Time Needed".
5. "Partial Only" selected: NumberField appears (max = requested qty).
6. "Price Changed" selected: NumberField appears + "Requires HyperQuote review" note in var(--color-warning).
7. Delivery scheduling section below line items: DatePicker (ship date, required), Select (delivery method: "Supplier Delivers" / "HyperQuote Pickup"), TextField (tracking number, optional), TextArea (notes, optional).

### PO Confirm/Reject Actions

- Sticky bottom bar: 48px height, flex row, border-top var(--color-border).
- "Confirm PO" button: green bg (var(--color-success)), white text, flex-1.
  - Opens ConfirmPOModal: "Confirm {N} of {M} items? {partial details if any}."
  - "Cancel" (outline) + "Confirm" (green bg).
  - Success: status -> "Confirmed". Toast: "PO confirmed."
- "Reject PO" button: red outline (var(--color-error)), px-24px.
  - Opens RejectPOModal: "Why are you rejecting this PO? This will be reviewed by HyperQuote." + required TextArea.
  - "Cancel" (outline) + "Reject PO" (red bg).
  - Success: status -> "Rejected". Toast: "PO rejected. HyperQuote has been notified."

### Confirmed Tab PO Cards

- Each card shows: PO reference, status badge ("Confirmed" / "In Production" / "Shipped"), ship date, tracking number, delivery progress.
- "Update Status" button: dropdown to advance status.
  - "Shipped" -> TextField for tracking number.
  - "Delivered" -> TextArea for delivery note.
- "Submit Invoice" button: navigates to Invoice Submission with PO pre-selected.

### Invoice Form

1. Related PO: React Aria ComboBox, lists confirmed/shipped POs without invoices. Required.
2. Selecting PO auto-populates line items.
3. Invoice number: TextField, required, Geist Mono display.
4. Invoice date: DatePicker, default today, required.
5. Line items: auto-populated, prices editable via inline NumberField.
6. Totals section: Subtotal + VAT (14%) + Total, calculated live, Geist Mono 18px 600.
7. Total mismatch warning: if manual total differs > 1% from calculated: amber banner "Your total doesn't match the calculated total. Please verify." var(--color-warning-bg).
8. PDF upload: required, drag-and-drop, max 10MB, PDF only.
9. Notes: TextArea, optional.
10. "Submit Invoice" button: blue bg, 48px, full width.
11. Toast: "Invoice submitted."

### Submitted Invoices Table

- Columns: Invoice #, Related PO, Date, Amount, Status.
- Status badges: "Submitted" (info), "Under Review" (warning), "Approved" (success), "Paid" (success), "Disputed" (error).
- All number columns in Geist Mono.

### Analytics KPI Cards

- 4 cards in a row (desktop), 2x2 grid (mobile).
- Each card: var(--color-surface) bg, rounded-xl, p-20px, min-width 200px.
- KPI label: Inter 500 12px var(--color-text-muted), uppercase, letter-spacing 0.05em.
- KPI value: Geist Mono 600 28px var(--color-text).
- Trend indicator: Lucide TrendingUp/TrendingDown 14px + Geist Mono 12px percentage.
  - Positive trend: var(--color-success).
  - Negative trend: var(--color-error).
- Cards: "Revenue", "Fill Rate", "On-Time Rate", "Quote Inclusion".

### Monthly Revenue Chart

- Bar chart: full width, 300px height, rounded-xl border.
- Blue bars (var(--color-primary)).
- Axis labels: Geist Mono 12px.
- Hover tooltip: exact value in Geist Mono, elevated glass card.
- Placeholder implementation (charting library deferred -- render as simple CSS/SVG bars).

### Product Performance Table

- Columns: Product, Views, Quote Inclusions, POs, Revenue, Win Rate.
- All numeric columns: Geist Mono 14px 400.
- Sortable columns (React Aria Table with sort descriptors).
- Top 20 products by default. "View All" link to expand.

### Analytics Date Range

- React Aria DateRangePicker in toolbar area.
- Default: last 30 days.
- Presets: "Last 7 days", "Last 30 days", "Last 90 days", "This year".

## Accessibility Contract

- All modals use React Aria Dialog with `isKeyboardDismissDisabled`
- Product table uses React Aria Table with proper column headers and sort indicators
- Inline edit NumberField: aria-label includes product name and field type (e.g., "Price for Portland Cement")
- Checkbox per PO line item: aria-label "Confirm {product name}"
- Reason select: aria-label "Rejection reason for {product name}"
- Tabs use React Aria Tabs with proper ARIA roles (tablist, tab, tabpanel)
- File upload drop zones: aria-label "Upload catalog file" with keyboard activation
- Status badge colors are NEVER the only indicator -- always paired with text labels
- Freshness colors are NEVER the only indicator -- relative time text always present
- Confidence scores: dot color + numeric percentage text
- Focus management: modal open traps focus, modal close returns focus to trigger
- Drawer: focus trap while open, Escape closes, focus returns to edit button
- PO detail: sticky bottom actions remain accessible via keyboard Tab order
- ComboBox for PO selection: proper listbox semantics with filter
- Chart: provide text alternative "Monthly revenue chart" + data table fallback for screen readers
- KPI cards: semantic heading structure (h3 for label, values in aria-live region on date range change)
