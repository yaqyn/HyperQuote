    **1. Create `InlineEditCell.tsx`** -- standalone React Aria NumberField for inline table editing:
    - Props: `{ value: number, onSave: (newValue: number) => Promise<void>, formatOptions?: Intl.NumberFormatOptions, locale: 'ar' | 'en' }`

    - Click div -> enter edit mode. On blur or Enter key -> call `onSave(localValue)`. If value unchanged, skip save.

    - Stop keyboard event propagation in edit mode to prevent React Aria Table row navigation conflicts.

    - Use `standardSchemaResolver` (NOT `zodResolver`).
    - Fields per UI-SPEC: Product name (read-only div, not input), Price (NumberField from `@hyperquote/forms`, required, currency prefix/suffix), MOQ (NumberField), Stock quantity (NumberField), Lead time (NumberField + "days" label), Notes (TextArea from react-aria-components).
    - Bottom: "Update Product" (blue, h-[44px], full width) + "Discard Changes" (text button, no fill).
    - Close on Escape key (use `useShortcut('Escape', onClose)`).
    - On submit: call `updateSupplierStock` with all changed fields, invalidate `['supplier-products']`, close drawer, show success toast.
    - Motion animation: `initial={{ x: locale === 'ar' ? -480 : 480 }}` `animate={{ x: 0 }}` spring enter. Exit tween.

    **2. Create `BulkUpdateDiff.tsx`:**
    - Props: `{ isOpen: boolean, onClose: () => void, locale: 'ar' | 'en' }`.
    - Renders in a `GlassElevated` modal (Dialog from react-aria-components with `isKeyboardDismissDisabled`).
    - Two phases:
      - Phase 1 (upload): "Download Current Prices" link (generates CSV from current products via PapaParse `Papa.unparse()`). File upload area for modified CSV.
      - Phase 2 (diff preview): Parse uploaded CSV with `Papa.parse()`. Compare by product ID. Show only changed rows. Each row: product name, field changed, old value (Geist Mono, `line-through text-red-600`), arrow, new value (Geist Mono, `text-green-600`). Unchanged rows hidden (not grayed -- hidden).
    - Confirmation: "Apply Changes" button (blue, 44px) -> GlassElevated confirmation modal: `t('supplier.bulkConfirm', { priceCount, qtyCount })`. "Cancel" + "Apply Changes" buttons.
    - On apply: call `bulkUpdatePrices` with the diff array (array-based `{ updates[] }` signature, NOT fileUrl), invalidate `['supplier-products']`, close, show toast.
    - Index by productId for O(1) lookup to avoid O(n*m) comparison (per Pitfall 3).
    - Import PapaParse: `import Papa from 'papaparse'`.

    **3. Create `PriceHistoryTable.tsx`:**
    - Props: `{ locale: 'ar' | 'en' }`.
    - `useQuery({ queryKey: ['supplier-price-history', page], queryFn: () => getSupplierPriceHistory({ data: { page, limit: 50 } }) })`.
    - React Aria Table with columns: Product, Old Price (Geist Mono, `line-through`), New Price (Geist Mono), Changed By, Date (Geist Mono via DateDisplay), Status (StatusBadge: "Applied" green, "Pending Review" yellow, "Rejected" red).

    - Pagination: same pattern as StockTable.
