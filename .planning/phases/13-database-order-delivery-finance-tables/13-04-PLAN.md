Tables to create (in FK order, handling circular dependency):
1. `invoices` — tenant_id, invoice_number (UNIQUE with tenant_id), order_id FK, delivery_id FK to deliveries(id), customer_id FK to customers(id), status (invoice_status enum). GENERATED column: `balance_due DECIMAL(15,2) GENERATED ALWAYS AS (total - amount_paid - adjustment_amount) STORED`. ~30 columns including ETA e-invoicing fields (eta_submission_id, eta_status, eta_uuid, digital_signature).
2. `invoice_items` — FK to invoices(id) ON DELETE CASCADE, order_items(id), products(id). quantity, unit_price, line_total, tax fields.
3. `invoice_disputes` — FK to invoices(id). dispute_type, status, description, resolution fields, sla_deadline.
4. `payments` — tenant_id, payment_number (UNIQUE with tenant_id), customer_id FK, invoice_id FK to invoices(id), status (payment_status enum). GENERATED column: `unapplied_amount DECIMAL(15,2) GENERATED ALWAYS AS (amount - applied_amount) STORED`. payment_method, reference, received_date.
5. `payment_applications` — FK to payments(id), invoices(id). applied_amount, applied_at.
6. `cheque_tracking` — FK to payments(id). cheque_number, bank_name, maturity_date, status (cheque_status enum), bounce fields. No direct customer_id — accessed via payments join.
7. `letters_of_credit` — tenant_id, customer_id FK, lc_number. GENERATED column: `amount_available DECIMAL(15,2) GENERATED ALWAYS AS (amount - amount_drawn) STORED`. Status DEFAULT 'draft' (NOT 'active' — see Research open question #3). Issuing/advising bank fields, expiry_date.
8. `returns` — tenant_id, return_number (UNIQUE with tenant_id), order_id FK, delivery_id FK to deliveries(id), customer_id FK. `credit_note_id UUID` column WITHOUT FK constraint (added after credit_notes created). Return reason, status, items JSONB.
9. `credit_notes` — tenant_id, credit_note_number (UNIQUE with tenant_id), invoice_id FK, customer_id FK, return_id FK to returns(id). GENERATED column: `remaining_amount DECIMAL(15,2) GENERATED ALWAYS AS (amount - applied_amount) STORED`. Reason, status.
10. `credit_note_applications` — FK to credit_notes(id), invoices(id). applied_amount, applied_at.
11. `withholding_tax_certificates` — tenant_id, invoice_id FK, certificate_number, tax_type (1% goods / 5% services), amount, certificate_date, uploaded_file_url.
12. `company_bank_accounts` — tenant_id, bank_name, account_number, iban, swift_code, currency, is_default.
13. `supplier_invoices` — tenant_id, supplier_invoice_number, supplier_id FK, supplier_po_id FK to supplier_pos(id), status, three_way_match fields, withholding_tax fields (1% goods, 5% services).
14. `supplier_invoice_items` — FK to supplier_invoices(id) ON DELETE CASCADE, products(id). quantity, unit_cost, line_total.
15. `ar_aging_snapshots` — tenant_id, snapshot_date, customer_id FK, current/30/60/90/120_plus bucket amounts, total_outstanding.
16. `revenue_recognition_events` — tenant_id, invoice_id FK, order_id FK, customer_id FK, product_id FK. GENERATED columns:
    - `gross_margin DECIMAL(15,2) GENERATED ALWAYS AS (revenue_amount - cost_amount) STORED`
    - `margin_percent DECIMAL(5,2) GENERATED ALWAYS AS (CASE WHEN revenue_amount > 0 THEN ((revenue_amount - cost_amount) / revenue_amount * 100) ELSE 0 END) STORED`
    - `fiscal_quarter INTEGER GENERATED ALWAYS AS (CEIL(fiscal_month / 3.0)::int) STORED`
