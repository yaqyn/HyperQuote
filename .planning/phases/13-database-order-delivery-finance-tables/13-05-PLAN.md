**Migration 020 — RLS Policies:**

For EVERY Phase 13 table (all ~55 tables created in Plans 01-04), apply:

```sql
ALTER TABLE {table} ENABLE ROW LEVEL SECURITY;
ALTER TABLE {table} FORCE ROW LEVEL SECURITY;
```

Then create policies using the 4 patterns from 13-RESEARCH.md Pattern 6:

**Pattern 1 — Internal users (tenant-scoped) — applies to ALL tables with tenant_id:**
```sql
DROP POLICY IF EXISTS {table}_internal_all ON {table};
CREATE POLICY {table}_internal_all ON {table}
  FOR ALL TO authenticated
  USING ((SELECT is_internal_user()) AND tenant_id = (SELECT current_tenant_id()))
  WITH CHECK ((SELECT is_internal_user()) AND tenant_id = (SELECT current_tenant_id()));
```

**Pattern 2 — External customers (customer-scoped) — tables with customer_id:**
Applies to: customers, customer_contacts, addresses (via customer), credit_applications, customer_feedback, orders, quotes (via customer_id), invoices, payments, returns, credit_notes, ar_aging_snapshots.
```sql
DROP POLICY IF EXISTS {table}_customer_select ON {table};
CREATE POLICY {table}_customer_select ON {table}
  FOR SELECT TO authenticated
  USING ((SELECT is_external_user()) AND customer_id = (SELECT current_customer_id()));
```

**Pattern 3 — External suppliers (supplier-scoped) — tables with supplier_id:**
Applies to: suppliers, supplier_contacts, supplier_price_lists, supplier_agreements, supplier_pos, supplier_po_items (via EXISTS through supplier_pos), supplier_inquiries, product_suppliers, supplier_invoices.
```sql
DROP POLICY IF EXISTS {table}_supplier_select ON {table};
CREATE POLICY {table}_supplier_select ON {table}
  FOR SELECT TO authenticated
  USING ((SELECT is_external_user()) AND supplier_id = (SELECT current_supplier_id()));
```

**Pattern 4 — Financial tables with MFA gate — add AAL2 to internal policy:**
Applies to: invoices, invoice_items, invoice_disputes, payments, payment_applications, cheque_tracking, letters_of_credit, credit_notes, credit_note_applications, withholding_tax_certificates, ar_aging_snapshots, revenue_recognition_events, supplier_invoices, supplier_invoice_items, company_bank_accounts.
```sql
DROP POLICY IF EXISTS {table}_internal_all ON {table};
CREATE POLICY {table}_internal_all ON {table}
  FOR ALL TO authenticated
  USING ((SELECT is_internal_user()) AND tenant_id = (SELECT current_tenant_id()) AND (auth.jwt()->>'aal') = 'aal2')
  WITH CHECK ((SELECT is_internal_user()) AND tenant_id = (SELECT current_tenant_id()) AND (auth.jwt()->>'aal') = 'aal2');
```

**Child tables without tenant_id** (order_items, quote_items, delivery_items, supplier_po_items, invoice_items, etc.) — use EXISTS subquery through parent:
```sql
CREATE POLICY {child}_internal_all ON {child}
  FOR ALL TO authenticated
  USING (EXISTS (SELECT 1 FROM {parent} p WHERE p.id = {child}.{parent_fk} AND (SELECT is_internal_user()) AND p.tenant_id = (SELECT current_tenant_id())));
```

**Driver-scoped tables:** deliveries (driver can see assigned), driver_locations, driver_shifts, vehicle_inspections, driver_jobs, driver_earnings.
```sql
CREATE POLICY {table}_driver_select ON {table}
  FOR SELECT TO authenticated
  USING ((SELECT is_external_user()) AND driver_id = (SELECT current_driver_id()));
```

**CRITICAL PITFALLS to handle:**
- Pitfall 5: DROP POLICY IF EXISTS before CREATE — some tables (products) already have RLS from Phase 2.
- Pitfall 6: Use correct table names (quote_items not quote_line_items, supplier_po_items not purchase_order_items). Skip tables not in Phase 13.
- Pitfall 7: cheque_tracking has no customer_id — use internal-only MFA policy (no customer-scoped policy).
- Pitfall 8: order_items has no tenant_id — use EXISTS through orders parent.
- Pitfall 10: Use `(SELECT current_tenant_id())` everywhere, NOT `current_setting('app.current_tenant_id')`.
- ALWAYS use `(SELECT auth.uid())` subquery form, not bare `auth.uid()`.
