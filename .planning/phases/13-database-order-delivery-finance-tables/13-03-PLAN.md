Create migration 015 with all delivery tables from BACKEND.md Section 3.9. Use `CREATE TABLE IF NOT EXISTS`.

Tables to create (in FK order):
1. `vehicles` — tenant_id, vehicle_number, type (vehicle_type enum), capacity fields, license plate, is_active. UNIQUE (tenant_id, vehicle_number).
2. `drivers` — tenant_id, auth_user_id FK to auth.users, driver_number, name, phone, license fields, status, vehicle_id FK to vehicles(id). UNIQUE (tenant_id, driver_number).
3. `delivery_routes` — tenant_id, route_number, route_date, driver_id FK to drivers(id), vehicle_id FK to vehicles(id), status, planned/actual fields, total_stops, optimization fields. UNIQUE (tenant_id, route_number).
4. `deliveries` — tenant_id, delivery_number, order_id FK to orders(id), route_id FK to delivery_routes(id), driver_id FK to drivers(id), vehicle_id FK to vehicles(id), warehouse_id FK to warehouses(id), status (delivery_status enum), address fields, scheduled/actual times, recipient fields. `invoice_id` column WITHOUT FK (added in Plan 04 after invoices created). UNIQUE (tenant_id, delivery_number).
5. `delivery_items` — FK to deliveries(id) ON DELETE CASCADE, order_items(id), products(id). quantity fields (planned, loaded, delivered, damaged, returned).
6. `proof_of_delivery` — FK to deliveries(id). photos JSONB, signature fields, gps location, notes, confirmed_by.
7. `drop_ship_pod` — FK to deliveries(id), supplier_pos(id). status, auto_confirm_deadline TIMESTAMPTZ, customer response fields, dispute fields.
8. `driver_locations` — **PARTITIONED TABLE**. BIGINT id GENERATED ALWAYS AS IDENTITY, tenant_id, driver_id, delivery_id, route_id, latitude, longitude, speed, heading, accuracy, recorded_at. `PRIMARY KEY (recorded_at, id)`. `PARTITION BY RANGE (recorded_at)`. **NO FK constraints** on driver_id/delivery_id/route_id (PostgreSQL limitation for partitioned tables).

   Create monthly partitions:
   ```sql
   CREATE TABLE driver_locations_2026_04 PARTITION OF driver_locations
     FOR VALUES FROM ('2026-04-01') TO ('2026-05-01');
   CREATE TABLE driver_locations_2026_05 PARTITION OF driver_locations
     FOR VALUES FROM ('2026-05-01') TO ('2026-06-01');
   CREATE TABLE driver_locations_2026_06 PARTITION OF driver_locations
     FOR VALUES FROM ('2026-06-01') TO ('2026-07-01');
   CREATE TABLE driver_locations_2026_07 PARTITION OF driver_locations
     FOR VALUES FROM ('2026-07-01') TO ('2026-08-01');
   ```

9. `vehicle_inspections` — FK to vehicles(id), drivers(id). inspection_type (pre_trip/post_trip), checklist_items JSONB, odometer, photos, pass/fail, notes.
10. `driver_shifts` — FK to drivers(id), vehicles(id). shift_start/end, start/end odometer, status, route_count, delivery_count.
11. `load_verifications` — FK to deliveries(id), drivers(id). scanned_items JSONB, weight_check, photos, verified_by, verified_at.
