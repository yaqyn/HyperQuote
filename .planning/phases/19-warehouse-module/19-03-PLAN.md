    **PickQueue.tsx** — Per spec section 4.6:
    - Fetch pick orders via TanStack Query (`getPickQueue`)
    - Each card: SO number, customer name, shipping time (Geist Mono), assigned truck/route, item count, total weight (Geist Mono, prominent)
    - Priority color on left border: red = ship within 2h, yellow = ship today, green = tomorrow+
    - Filter bar: route, truck, priority, product type (React Aria Select components)
    - Sorted by shipping deadline ascending
    - Tap card -> setSelectedPickOrderId -> show DirectedPicking

    **DirectedPicking.tsx** — Per spec section 4.7, step-by-step per item:
    - Fetch pick steps via TanStack Query (`getPickSteps`)
    - StepIndicator showing "Item X of Y"
    - Per step:
      1. Navigate direction: "GO TO: {locationPath}" with location path displayed prominently (e.g., "WH-A / CEMENT / ROW-2 / Bay 04 / Floor Level")
      2. Product info: name, SKU, lot number (Geist Mono), FEFO note if fefoEnforced: "Oldest lot — expires {expiryDate}" in amber text, quantity to pick (Geist Mono)
      3. **Two-scan verification:**
         - ScanInput: "Scan location barcode" with expectedValue from step data
         - ScanInput: "Scan product barcode" with expectedValue (only enabled after location scan)
      4. Quantity entry: LargeNumberInput for partial pallet picks
      5. Exception buttons: `[Short Pick]` `[Skip Item]` `[Substitute]` — each opens PickExceptions dialog
    - `[Confirm Pick]` button — validates FEFO via `validateFEFOPick()` from fefo.ts. If invalid (newer lot picked when older available), show error: "Older lot available at {location}" and BLOCK the pick (per locked decision: FEFO enforcement is strict). If valid, call `confirmPick` server function.
    - WeightTracker rendered at bottom of every step

    **PickExceptions.tsx** — React Aria Dialog for exception handling:
    - Props: `type: PickException, onConfirm, onCancel`
    - Short Pick: show available quantity at current location, pick what's available, system will redirect to next location with same product. Note input for reason.
    - Skip Item: reason select (cannot access, blocked, equipment issue). Queue for re-pick later.
    - Substitute: show system-suggested substitutes from pick step data, select substitute product, scan substitute barcode.
    - `isKeyboardDismissDisabled` on the dialog

    **WeightTracker.tsx** — Running weight display:
    - Visual progress bar: "37,500 lbs / 48,000 lbs — 78%" style (all Geist Mono)
    - Props: `currentWeightKg, maxCapacityKg`
    - Display converts from kg to display unit based on locale
    - Color: green <75%, yellow 75-90%, red >90%
    - Percentage calculated: `Math.round((currentWeightKg / maxCapacityKg) * 100)`
    - Bar uses CSS width with bg-[#2563EB] (blue) fill
  </action>
