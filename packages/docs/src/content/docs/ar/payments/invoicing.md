الفاتورة في هايبر كوت تُنشأ تلقائياً في اللحظة التي يتأكد فيها التوصيل — سواء عبر إثبات التوصيل من السائق أو تأكيد الاستلام من العميل. هذه الأتمتة تضمن أن لا فاتورة تتأخر ولا توصيلة تمر دون فوترة.

## إنشاء الفاتورة

الفاتورة تُنشأ من بيانات الطلب وتأكيد التوصيل وتتضمن كل العناصر المطلوبة قانونياً:

- **بيانات البائع** — اسم الشركة بالعربية، رقم السجل التجاري، الرقم الضريبي (٩ أرقام)، العنوان، الشعار والختم الرقمي
- **بيانات المشتري** — اسم الشركة، الرقم الضريبي، اسم جهة الاتصال
- **بيانات الفاتورة** — الرقم المرجعي، التاريخ، رقم الطلب المرتبط
- **البنود** — اسم المنتج ثنائي اللغة، رمز المنتج (SKU)، كود EGS/GPC، وحدة القياس، الكمية، سعر الوحدة قبل الضريبة، إجمالي البند
- **التوصيل** — كبند مستقل بتسعير حسب المنطقة
- **الإجمالي** — الإجمالي الفرعي، ١٤٪ ضريبة قيمة مضافة، الإجمالي النهائي
- **شروط الدفع** — المدة والطريقة بوضوح
- **الختم الرقمي** (ختم الشركة) — توقعه الشركات المصرية في معاملاتها التجارية

## حالات الفاتورة

الفاتورة تمر بعدة حالات:

- **مسودة** → **مُرسلة** → **مطلع عليها** → **مسددة جزئياً** → **مسددة بالكامل**
- مسارات بديلة: **متأخرة** → **في التحصيل** / **متنازع عليها** → **مسواة** / **معدلة** / **ملغاة** / **مشطوبة**

الفواتير المتأخرة ٣٠ يوماً تُرسل تذكيراً تلقائياً. بعد ٦٠ يوماً تُصعد لمدير الائتمان مع تجميد الطلبات الجديدة.

## تنسيق المستند

الفاتورة متاحة كملف PDF بمواصفات محددة:

- **صفحة A4** قابلة للطباعة بالأبيض والأسود — لأن فرق المشتريات تطبع وتختم وتحفظ
- **حجم ملف مناسب لواتساب** — لسهولة المشاركة
- **باللغة العربية** — وفقاً لمتطلبات مصلحة الضرائب المصرية
- **يتضمن الختم الرقمي للشركة** — معيار متوقع في المستندات التجارية المصرية

الفاتورة تظهر أيضاً في تبويب المستندات ببوابة العميل وتُرسل عبر البريد الإلكتروني.

## الفاتورة المبدئية

بالإضافة للفاتورة النهائية، النظام يُنشئ فاتورة مبدئية (Proforma Invoice) من نفس بيانات عرض السعر. الفاتورة المبدئية ضرورية في مصر لعدة أغراض: فتح خطابات الاعتماد، موافقات الشراء الداخلية في الشركات، والاستيراد. تحتوي على بيانات البنك ومنسقة كفاتورة حقيقية.

## إشعارات الدائن والمدين

الفواتير الإلكترونية المرسلة لمصلحة الضرائب **لا يمكن حذفها**. أي تعديل على الفاتورة يتم عبر إشعار دائن (تخفيض) أو إشعار مدين (زيادة). سواء كان التعديل بسبب مرتجعات أو تلف أو تعديل أسعار — الآلية واحدة: إشعار موقع رقمياً يُرسل لمصلحة الضرائب بنفس صيغة الفاتورة الأصلية.
